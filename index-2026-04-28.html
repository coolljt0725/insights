Linux 内核社区热点与趋势

Linux 7.1-rc1 发布，正式关闭合并窗口并清理旧硬件支持
Linus Torvalds 发布了 Linux 7.1 的第一个候选版本，标志着本次合并窗口正式关闭。该版本引入了近 1.3 万个非合并变更集，在增加大量新特性的同时，社区也开始着手减轻维护负担，包括逐步淘汰 i486 架构支持、移除部分过时的网络硬件驱动以及未被广泛采用的 SoC 支持。尽管清理了旧代码，但由于新功能的加入，代码总行数依然呈增长态势。

Linux 7.1 主线内核实现 ARM 架构的原生实时性（RT）支持
在 Linux 7.1 中，ARM 架构正式支持在主线内核中构建实时内核（PREEMPT_RT），不再需要依赖树外补丁。这一进展对于嵌入式和工业控制领域具有重要意义，意味着开发者可以直接使用标准内核源码来实现高性能的实时响应。这是内核实时性补丁集（RT-patchset）完全并入主线过程中的又一里程碑。
原文：With Linux 7.1 The Mainline Kernel Now Supports Real-Time "RT" On ARM

内核功耗管理工具更新，支持 x86 SoC 滑块调节
Linux 7.1 在内核源码树内的 x86_energy_perf_policy 工具中增加了对 SoC 滑块（Slider）的支持。这一更新允许用户更精细地控制现代 x86 处理器的能量与性能平衡，特别是在移动设备和低功耗服务器场景下。该功能在合并窗口关闭前由 Linus 亲自合入，进一步增强了 Linux 对硬件电源特性的调优能力。
原文：Linux 7.1 Adds SoC Slider Support To x86_energy_perf_policy Utility

多版本稳定版内核发布，修复关键漏洞
内核维护者 Greg Kroah-Hartman 发布了包括 7.0.2、6.18.25、6.12.84 和 6.6.136 在内的四个稳定版内核更新。这些版本包含了针对驱动程序、内存管理及文件系统的多项重要修复。社区强烈建议所有生产环境用户及时升级，以确保系统的稳定性和安全性。

学术界最新研究

Transformer 训练的光谱生命周期研究：揭示权重矩阵的演变规律
arXiv 论文 (2604.22778) 对 Transformer 预训练过程中的权重矩阵进行了系统的奇异值分解（SVD）研究。研究发现了“瞬态压缩波”现象，即稳定秩压缩会像波一样从前层传导至后层，且后层最终会出现过度压缩。这一发现为理解大模型的训练动力学提供了新的视角，有助于优化模型架构和训练策略。
原文：The Spectral Lifecycle of Transformer Training

KARL 框架：通过感知知识边界的强化学习减少 LLM 幻觉
针对大语言模型（LLM）在面对超出其知识范围的问题时容易产生幻觉的问题，研究者提出了 KARL 框架。该框架引入了“知识边界感知奖励”机制，动态评估模型的知识边界，并奖励正确的回答或引导模型在未知领域选择“弃权”。实验表明，这种方法在减少幻觉的同时，避免了传统强化学习导致的过度谨慎问题。
原文：KARL: Mitigating Hallucinations in LLMs via Knowledge-Boundary-Aware Reinforcement Learning

LARS 框架：重新思考端侧 LLM 适配中的内存效率
论文 (2604.22783) 挑战了“参数高效即内存高效”的普遍假设，指出 LoRA 等方法虽然减少了参数，但中间张量仍会导致端侧设备内存溢出。研究者提出了 LARS 框架，通过约束激活子空间而非模型参数，实现了内存消耗与序列长度的解耦。这一研究对于在手机、嵌入式设备等资源受限环境下部署大模型具有重要应用价值。
原文：Parameter Efficiency Is Not Memory Efficiency: Rethinking Fine-Tuning for On-Device LLM Adaptation

AutoCompress：通过关键层隔离实现高效的 Transformer 压缩
研究人员发现，在小型 Transformer 中，第 0 层承载的任务关键信息量远超其他层（高达 60 倍）。基于此，AutoCompress 提出了“关键层隔离（CLI）”架构，在保持第 0 层全维度的同时，对中间层进行大幅压缩。在 GPT-2 Medium 上的实验显示，该方法在减少 59.5% 参数的情况下，依然保持了极高的模型性能。
原文：AutoCompress: Critical Layer Isolation for Efficient Transformer Compression
