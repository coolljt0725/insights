Linux 7.1-rc6 发布，内核发布节奏回归正常
Linus Torvalds 发布了 Linux 7.1 的第六个候选版本（rc6）。虽然本周的代码变动量依然不小，但相比于异常庞大的 rc5 已经有所收缩，Linus 表示目前没有发现令人担忧的重大问题。如果后续测试顺利，Linux 7.1 稳定版预计将在 6 月中旬正式发布。

内核文档将隐藏 "clearcpuid" 参数以减少误用
Linux 7.1-rc6 决定将 clearcpuid 内核参数的文档从公开说明中隐藏。该参数通常用于在内核层级禁用特定的 CPUID 特性（如 AVX-512），常被开发者用于性能对比测试。社区认为过度使用该参数可能导致系统不稳定，因此决定通过隐藏文档的方式来劝阻普通用户使用。
原文：Linux 7.1-rc6 To Hide The Documentation On "clearcpuid" Feature

Linux 计划于 2026 年彻底禁用微软 RNDIS 协议驱动
由于微软的远程网络驱动程序接口规范（RNDIS）协议存在长期的安全隐患，Linux 社区正计划在 2026 年彻底禁用相关驱动。RNDIS 曾广泛用于通过 USB 共享网络，但其设计陈旧且易受攻击。目前社区推荐用户转向更现代、更安全的替代方案，如 CDC-NMS 或 NCM 协议。

Kubernetes v1.36 强化负载感知调度与 PodGroup API
Kubernetes v1.36 版本引入了显著的架构演进，通过 PodGroup API 实现了对 AI/ML 和批处理任务的原子化调度。新版本将 Workload API 作为静态模板，而由 PodGroup 处理运行时状态，解决了传统 Pod 逐个调度在复杂任务中的局限性。这为未来更高效的“全有或全无”（Gang Scheduling）调度奠定了基础。
