Linux 内核社区热点与趋势

Linux 7.0-rc1 正式发布，合并窗口关闭
Linus Torvalds 发布了 Linux 7.0 的第一个候选版本（rc1），标志着该开发周期的合并窗口正式关闭。虽然版本号从 6.x 跳跃到 7.0 主要是因为 Linus 习惯在 x.19 之后进行大版本更迭，但此版本确实包含大量新特性，如对 AMD Zen 6 处理器的初步支持和 Rust 语言工具链的进一步集成。这一版本的发布预示着内核开发进入了稳定和修复阶段。
原文：Linux 7.0-rc1 Released With Many New Features

Linux 7.0 贡献名单新增 Linux-Next 创始人
在 Linux 7.0-rc1 发布前的最后时刻，内核贡献名单（CREDITS）正式加入了 Stephen Rothwell。Stephen 在过去 18 年里一直负责维护 Linux-Next 分支，这是内核开发流程中至关重要的一环，用于集成和测试即将进入主线的代码。这一举动体现了社区对长期维护基础设施贡献者的认可。
原文：Linux 7.0 Credits Now Honor The Creator Of Linux-Next

内核引入虚拟交换空间（Virtual Swap Spaces）以优化内存交换性能
内核开发者 Nhat Pham 提交了一系列补丁，旨在通过引入单一的“虚拟交换空间”来替换现有的交换表结构。这一改进解决了长期以来交换子系统在性能和管理上的痛点，能够更高效地跟踪交换缓存状态。该工作是内核内存管理现代化的重要一步，特别是在高负载服务器环境下具有显著意义。
原文：Modernizing swapping: virtual swap spaces

Linux 7.0 将默认启用 AccECN 以优化 TCP 拥塞控制
“更精确的显式拥塞通知”（AccECN）机制将在 Linux 7.0 中默认开启，该机制通过改进 TCP 协议反馈网络拥塞的方式来提升传输效率。AccECN 能够提供比传统 ECN 更细粒度的拥塞信号，有助于减少数据包丢失并降低延迟。这一变化将惠及公共互联网和私有数据中心网络。
原文：More accurate congestion notification for TCP

Asahi Linux 项目组分享了在 Apple M 系列芯片上运行 Linux 的最新进展，其上游化补丁数量已显著减少，显示出更多代码已被主线内核接受。目前 GPU 驱动程序仍是最大的开发挑战，代码量超过 2 万行，但整体系统稳定性已大幅增强。该项目继续引领着非 x86 架构 Linux 生态的边界。

学术界最新研究

LDOS：迈向学习驱动的操作系统
SIGOPS 发表了一篇关于“学习驱动操作系统”（LDOS）的研究，探讨了如何利用机器学习模型替换内核中的传统启发式算法。研究指出，通过在调度、内存管理和预取等环节引入在线学习，系统可以更好地适应动态负载。这一方向被认为是未来十年操作系统架构演进的核心趋势之一。
原文：LDOS: Toward a Learning-Directed Operating System

TempoNet：基于 Transformer 和强化学习的实时调度器
arXiv 披露了一项名为 TempoNet 的研究，提出了一种结合 Transformer 架构和深度 Q 学习的实时调度方案。该系统通过“紧急程度令牌化”技术，能够在亚毫秒级时间内对无序任务集进行全局推理。实验表明，该调度器在工业级多核环境下的截止日期达成率显著优于传统算法。
原文：TempoNet: Slack-Quantized Transformer-Guided Reinforcement Scheduler

BioBridge：通过持续预训练增强 LLM 的生物学推理能力
研究人员提出了 BioBridge 框架，旨在解决通用大模型在蛋白质序列理解方面的不足。该框架采用领域增量持续预训练（DICP）技术，将蛋白质领域知识与通用推理能力同步注入模型，有效缓解了灾难性遗忘。这一研究为 AI 在生物制药和生命科学领域的应用提供了更强的底座模型。
原文：BioBridge: Bridging Proteins and Language for Enhanced Biological Reasoning

LATMiX：针对 LLM 微缩放量化的可学习仿射变换
针对大语言模型在量化过程中出现的离群值问题，LATMiX 研究提出了一种可学习的仿射变换方法。该方法能够显著提高模型在 4 位及以下低比特量化时的鲁棒性，特别是在现代硬件支持的微缩放（MX）数据格式下表现优异。这项技术对于在边缘设备上部署高性能大模型具有重要价值。
原文：LATMiX: Learnable Affine Transformations for Microscaling Quantization of LLMs
