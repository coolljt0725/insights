学术界最新研究

MetaKube：基于经验感知的 Kubernetes 故障诊断 LLM 框架
研究人员提出了 MetaKube，这是一个能够从运维经验中学习的 LLM 框架，用于 Kubernetes 的故障诊断。它通过情景模式记忆网络（EPMN）抽象历史解决案例，并利用元认知控制器在直觉匹配和深度因果探索之间动态切换。实验表明，该框架在处理复杂集群故障时比静态知识库模型具有更高的准确率和效率。
原文：MetaKube: An Experience-Aware LLM Framework for Kubernetes Failure Diagnosis

从命令式到声明式：面向 LLM 智能体的友好操作系统接口
针对 LLM 智能体在操作图形界面（GUI）时步骤繁琐且易错的问题，论文提出了声明式模型接口（DMI）。DMI 将现有的 GUI 抽象为访问、状态和观察三个声明式原语，实现了策略与机制的分离。这种新型 OS 接口让 LLM 只需关注高层语义规划，从而显著提升了计算机自动化任务的成功率。
原文：From Imperative to Declarative: Towards LLM-friendly OS Interfaces for Boosted Computer-Use Agents

AscendOptimizer：华为昇腾 NPU 算子优化的强化学习智能体

原文：AscendOptimizer: Episodic Agent for Ascend NPU Operator Optimization

APreQEL：面向边缘端 LLM 的自适应混合精度量化
为了在资源受限的边缘设备上部署 LLM，APreQEL 提出了一种自适应混合精度量化方案。该研究发现不同模型层对精度降低的敏感度不同，且内存消耗与计算吞吐量并不完全线性相关。通过动态调整各层的量化位数，APreQEL 在保持模型推理能力的同时，大幅优化了边缘设备的响应速度和隐私保护能力。
