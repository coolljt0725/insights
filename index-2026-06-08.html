学术界最新研究

AgileOS：为受保护的 CUDA 服务设计的 GPU 操作系统层
来自 arXiv 的研究提出了 AgileOS，这是一种新型的 GPU 操作系统层，旨在为 GPU 驻留服务提供类似操作系统的保护机制。当前 CUDA 模型中应用直接拥有上下文，导致服务元数据和内存暴露给不可信内核。AgileOS 通过隔离应用与服务状态，解决了现代 GPU 应用在交互存储、网络和库时的安全隔离难题。
原文：AgileOS: A GPU Operating System Layer for Protected CUDA Services

原文：Mru: A Fault-Tolerant Operating System for Thousand-Year Autonomous Operation
