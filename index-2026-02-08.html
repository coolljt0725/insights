工业界最新动向

Intel 疑似停止其“按需付费”软件定义硅片技术
Intel 在 2021 年推出了“软件定义硅片”（SDSi）功能，允许用户通过付费激活处理器中内置的额外硬件加速器。然而，最新的 Linux 内核补丁显示 Intel 正在悄悄撤回这一被称为“Intel On Demand”的功能支持。这标志着 Intel 在服务器市场尝试的这种硬件解锁商业模式可能并未达到预期效果，正逐渐淡出视野。
原文：Intel Appears To Have Quietly Sunset "On Demand" Software Defined Silicon

Wine 11.2 发布，显著提升 Linux 下 Adobe Photoshop 的兼容性
开源兼容层 Wine 发布了 11.2 版本，其开发分支 Wine-Staging 引入了数百个实验性补丁。本次更新的重点是改进了 Adobe Photoshop 安装程序在 Linux 上的运行表现，解决了长期以来困扰用户的安装中断问题。随着兼容性的不断增强，Linux 用户在运行专业 Windows 生产力软件方面将获得更顺滑的体验。
原文：Wine-Staging 11.2 Brings More Patches To Help Adobe Photoshop On Linux

Linux From Scratch 宣布停止支持 System V 初始化系统
著名的 Linux From Scratch (LFS) 项目宣布将不再维护基于 System V 的版本，未来将全面转向 systemd。官方表示，由于 LFS 完全依赖志愿者，同时维护两套初始化系统的工作量巨大，且上游软件包对 systemd 的依赖日益增加，不得不做出取舍。这一决定反映了 systemd 在现代 Linux 生态中已占据绝对的主导地位。
原文：Linux from Scratch to drop System V versions

内存安全语言 Jule 崭露头角，成为 C/C++ 的潜在替代者
随着美国政府等机构呼吁在关键系统中使用内存安全语言，开源项目 Jule 引起了广泛关注。Jule 旨在提供高性能的同时保证内存安全，其语法设计参考了 Go 和 Rust，力求在开发效率与系统级控制之间取得平衡。该语言的兴起为需要高性能且对安全敏感的底层开发提供了新的选择。
原文：Memory-Safe Jule language emerges as C/C++ alternative

Cloudflare 发布 2025 年第四季度 DDoS 威胁报告，攻击规模创纪录
Cloudflare 的最新报告显示，2025 年 DDoS 攻击数量翻了一番，其中网络层攻击增长了 700%。报告记录了一次峰值达 31.4 Tbps 的超大规模攻击，刷新了历史记录。这表明网络安全形势日益严峻，企业需要更强大的自动化防御机制来应对超大规模的流量冲击。
原文：2025 Q4 DDoS threat report: A record-setting 31.4 Tbps attack caps a year of massive DDoS assaults

学术界最新研究

GCC 编译器将引入内核控制流完整性（CFI）支持
控制流完整性（CFI）是防御内核漏洞攻击的关键技术，此前 Linux 内核主要依赖 Clang 的实现。开发者 Kees Cook 近期向 GCC 提交了补丁集，旨在将 -fsanitize=kcfi 等功能引入 GCC 17。这一研究成果将使习惯使用 GCC 工具链的开发者也能获得与 Clang 相当的内核安全防护能力。
原文：Kernel control-flow-integrity support comes to GCC

Willow 协议：为不确定的网络未来设计的通信框架
在 FOSDEM 2026 上，研究人员展示了名为 Willow 的新型通信协议，专注于在不稳定或受限的网络环境下实现高效的数据同步。该协议通过精简的元数据设计和冲突解决机制，试图解决分布式系统在极端条件下的可靠性问题。这项研究为物联网、边缘计算及去中心化应用提供了新的底层通信思路。
原文：Willow - Protocols for an uncertain future

自动化平铺算法研究：仅需 5 个瓦片实现自动布局
一项关于图形界面自动布局的研究提出了一种极简的算法，仅通过 5 种基础瓦片即可实现复杂的自动平铺效果。该研究探讨了如何通过逻辑组合简化游戏开发和 UI 设计中的空间填充问题，降低了计算复杂度。这种方法对于资源受限的嵌入式系统或需要快速渲染的图形引擎具有较高的参考价值。
原文：Implementing Auto Tiling With Just 5 Tiles

Linux 内核社区热点与趋势

Linux 内核引入机器学习库 ML-Lib 的争议性提案
开发者 Viacheslav Dubeyko 提交了一份在 Linux 内核中集成机器学习库的 RFC 提案，旨在通过 ML 模型优化内核子系统的配置和逻辑。该库支持数据采集、模型训练和推理，可用于 eBPF 逻辑合成等场景。尽管这一想法极具前瞻性，但在内核社区引发了关于内核膨胀和维护复杂性的激烈讨论。
原文：Machine Learning library in Linux kernel

Linux 6.19 正式版发布，6.20 或将更名为 Linux 7.0
Linux 6.19 稳定版已正式发布，带来了大量针对 Intel 和 AMD 处理器的性能优化及新硬件支持。按照 Linus Torvalds 过去在 X.19 版本后升级主版本号的习惯，下一个版本极有可能被命名为 Linux 7.0。目前 -next 分支已经积压了大量激动人心的新特性，预示着下一个合并窗口将非常繁忙。
原文：A Lot Of Exciting Changes To Look Forward To With Linux 6.20 -- Or Linux 7.0

内核交换子系统现代化：彻底告别旧有的 Swap Map 结构
Linux 内核正在对陈旧的交换（Swap）子系统进行大规模重构，计划用新的“交换表”（Swap Table）结构取代原有的 Swap Map。这一改进旨在简化内存管理逻辑并提升在高负载下的交换效率。完成这一系列现代化工作后，Linux 的内存回收和交换性能预计将得到显著提升。
原文：Modernizing swapping: the end of the swap map

Tyr 项目：为 Arm Mali GPU 开发 Rust 语言驱动程序
在 Linux Plumbers 会议上，开发者展示了使用 Rust 编写的 Arm Mali GPU 驱动原型 Tyr。随着 DRM 子系统计划在未来一年内强制要求新驱动使用 Rust 编写，Tyr 项目成为了这一趋势的先行者。该项目证明了 Rust 在复杂图形驱动开发中的可行性，并为内核驱动的安全性提供了新保障。
原文：The future for Tyr

Kubernetes 1.35 引入“原地重启 Pod”功能，大幅提升 AI/ML 效率
Kubernetes v1.35 引入了一项备受期待的 Alpha 特性：原地重启 Pod 中的所有容器。相比于传统的删除并重建 Pod，这种方式能以极低的资源开销重置应用状态，特别适合需要频繁恢复状态的 AI 训练和机器学习任务。这一特性标志着 Kubernetes 正在向支持更复杂、更高效的工作负载管理演进。
原文：Kubernetes v1.35: New level of efficiency with in-place Pod restart

Ingress NGINX 宣布将于 2026 年退休，社区敦促用户迁移
Kubernetes 指导委员会发布声明，确认 Ingress NGINX 项目由于缺乏维护者，将于 2026 年 3 月正式停止维护。官方强烈建议用户立即开始向 Gateway API 或其他第三方控制器（如 Cilium）迁移，以避免未来的安全风险。这一决定对全球约半数的云原生环境将产生深远影响。
原文：Ingress NGINX: Statement from the Kubernetes Steering and Security Response Committees

CNCF 迎来新沙箱项目 Cedar：云原生授权策略语言
由 AWS 开源的授权策略语言 Cedar 正式加入 CNCF 沙箱。Cedar 旨在为云原生环境提供快速、安全且可分析的授权控制，允许开发者以自然语言风格定义复杂的访问策略。加入 CNCF 将有助于 Cedar 在更广泛的开源生态中获得采用和标准化。
原文：Cedar Joins CNCF as a Sandbox Project

Kubernetes 引入节点就绪控制器（Node Readiness Controller）
为了解决现代集群中节点依赖项（如网络插件、GPU 驱动）复杂的初始化问题，Kubernetes 推出了节点就绪控制器。该系统通过声明式的方式管理节点污点（Taints），确保只有在所有基础设施需求满足后，节点才会被标记为 Ready。这增强了集群在引导过程中的健壮性，防止 Pod 调度到尚未完全准备好的节点上。
原文：Introducing Node Readiness Controller
