Linux 7.1 正式版发布，引入多项重量级更新
Linus Torvalds 提前发布了 Linux 7.1 稳定版内核。该版本包含大量关键变更：彻底重写了 NTFS 文件系统驱动，移除了对过时 486 架构的支持，并为 clone() 系统调用增加了新标志以简化进程管理。此外，新版本还增强了 io_uring 对 BPF 的支持，并为 ublk 用户态块设备驱动引入了零拷贝 I/O 支持。

Zinnia：使用 Rust 编写的模块化 64 位类 Unix 内核
Zinnia 是一个新兴的开源项目，旨在利用 Rust 语言的内存安全特性构建一个现代化的类 Unix 内核。它采用模块化设计，支持 64 位架构，并试图在保持 POSIX 兼容性的同时，解决 C 语言内核中常见的安全漏洞。该项目目前已引起 Rust 社区和系统开发者的广泛关注。
