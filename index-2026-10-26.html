Google C 语言版 Binder 驱动被移除，Rust 版正式接棒

上下文内存虚拟化（CMV）：LLM 智能体的状态管理新范式
借鉴操作系统的虚拟内存概念，研究者提出了 CMV 系统，将 LLM 的累积理解视为版本控制的状态。通过有向无环图（DAG）模型，CMV 实现了上下文的快照、分支和修剪，支持在独立并行会话中重用上下文。这种“结构化无损修剪”算法能有效解决长任务中的信息丢失问题。
原文：Contextual Memory Virtualisation: DAG-Based State Management and Structurally Lossless Trimming for LLM Agents

Muon 已成为大模型训练中的热门优化器，但其理论基础一直不明。该研究探讨了梯度噪声几何形状如何塑造 Muon 的预调理（Preconditioning）优势。研究发现，在各向同性噪声下 Muon 优势有限，但在处理具有异构任务频率的结构化噪声时，Muon 能显著加速学习过程。

CuraLoc：通过规划代码检查实现仓库级故障定位

原文：CuraLoc: Repository-Level Fault Localization via Planned Code Inspection
