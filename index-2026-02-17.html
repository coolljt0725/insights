Linux 内核社区热点与趋势

Linux 7.0 合并窗口开启，多项重量级特性涌入
Linux 7.0 合并窗口现已正式开启，目前已接受超过 7600 个非合并提交。尽管版本号遵循常规递增逻辑，但 7.0 版本引入了包括 AMD Zen 5 地址转换支持、RISC-V 用户态控制流完整性（CFI）以及更多 Rust 驱动核心增强等关键特性。这标志着内核在硬件支持多样性和内存安全语言集成方面迈出了重要一步。

紧急发布 Linux 6.19.2 及多个 LTS 版本以修复启动故障
在 Linux 6.19.1 发布后不久，社区发现了一个导致部分系统无法启动的严重回归问题。稳定版维护者 Greg Kroah-Hartman 迅速发布了 6.19.2 以及 6.18.12、6.12.73 和 6.6.126 等多个长期支持（LTS）版本，通过回滚问题提交来解决该故障。官方建议如果当前系统运行正常则无需升级，但受启动问题困扰的用户应立即更新。

Linux 7.0 增强 Rust 驱动支持并优化 PCI 子系统
Linux 7.0 内核在驱动核心层面进行了多项改进，旨在进一步降低 Rust 语言编写内核驱动的门槛。同时，PCI 子系统也进行了更新，更好地隔离了过时的 CardBus 代码，以避免在现代 PC 设备上产生干扰。这些变动体现了内核在清理遗留代码的同时，积极拥抱现代编程范式的趋势。

内核引入自定义启动 Logo 功能并移除陈旧芯片组支持
Linus Torvalds 近期合并了允许在编译时轻松替换 Tux 企鹅启动 Logo 的代码，为发行版和嵌入式设备提供了更便捷的定制化手段。与此同时，Linux 7.0 正式移除了拥有 28 年历史的 Intel 440BX 芯片组相关驱动，标志着内核正在逐步清理极老旧硬件的支持以减轻维护负担。
