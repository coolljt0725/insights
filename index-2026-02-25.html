Linux 内核社区热点与趋势

Linux 7.0-rc1 正式发布，合并窗口关闭
Linus Torvalds 已正式发布 Linux 7.0-rc1，标志着该版本合并窗口的结束。本次合并窗口共包含 11,588 个非合并提交，虽然第二阶段主要以错误修复为主，但仍有一些意外收获，如 rtl8723bs 驱动获得了大量代码清理。Linus 还在发布说明中幽默地提到，未来将由「不害怕两位数版本号」的人接管 Linux。
原文：Kernel prepatch 7.0-rc1

Linus Torvalds 移除旧版 Kconfig 选项以减少内核日志垃圾信息
Linus Torvalds 亲自编写并合并了一个补丁，移除了 WARN_ALL_UNSEEDED_RANDOM 这一 Kconfig 选项。该选项最初旨在提醒开发者注意未初始化的随机数生成器，但在某些系统上会导致产生大量无意义的内核日志，造成严重的日志污染。此举体现了内核社区在提升系统可维护性和减少冗余警告方面的持续努力。
原文：Torvalds Drops Old Linux Kconfig Option to Address Tiresome Kernel Log Spam

内核拟引入 clone3() 新标志，引发安全模型争议
Christian Brauner 提议为 clone3() 系统调用增加两个新标志，其中一个涉及 AUTOREAP 功能，旨在改变进程管理方式。该提案利用了近年来发展的 pidfd API，旨在提供更确定、更安全的进程操作句柄。然而，由于该功能涉及对内核现有安全模型的底层修改，目前在社区内引发了不小的争议。
原文：As ye clone(), so shall ye AUTOREAP

AMD 为 Linux 提交 SEV-SNP BTB 隔离补丁以增强机密计算安全
AMD 提交了一系列 Linux 内核补丁，旨在为 SEV-SNP（安全加密虚拟化-安全嵌套分页）引入分支目标缓冲（BTB）隔离支持。此举是为了进一步增强机密计算环境下虚拟机的安全性，防止潜在的侧信道攻击。随着企业对云端隐私保护需求的增加，此类硬件级安全特性的内核支持变得至关重要。

学术界最新研究

GPU 任务的实时调度与分析：利用依赖性与并行性
arXiv 论文（2602.20826）提出了一种针对有向无环图（DAG）结构的 GPU 任务调度方法。研究指出，复杂的内核间数据依赖和资源竞争会导致执行时间不可预测，通过该方法可以缩减并预测 DAG 响应时间。这对于自动驾驶等对延迟极其敏感的安全关键型应用具有重要意义。
原文：Exploiting Dependency and Parallelism: Real-Time Scheduling and Analysis for GPU Tasks

主权内核：为可验证的 AI 智能体执行提供历史记录权利
研究人员提出了一种名为「主权内核（Sovereignty Kernel）」的系统架构（arXiv:2602.20214），旨在为 AI 智能体的行为提供不可篡改、可独立验证的记录。该研究响应了欧盟 AI 法案对高风险系统自动日志记录的要求，确保个人硬件上的智能体行为对用户透明且可追溯。
原文：Right to History: A Sovereignty Kernel for Verifiable AI Agent Execution

真相光谱假设：LLM 如何在线性空间编码真实性
论文（arXiv:2602.20273）探讨了大语言模型是否线性编码真实性的争议，提出了「真相光谱假设」。研究发现，模型的表征空间包含从领域通用到领域特定的多个方向。虽然线性探测在多数领域表现良好，但在面对谄媚式谎言时会失效，通过跨领域联合训练可以恢复强大的通用探测性能。
原文：The Truthfulness Spectrum Hypothesis

MoBiQuant：面向令牌自适应弹性大模型的混合位量化框架
针对云端和边缘设备多变的计算资源需求，研究者提出了 MoBiQuant 框架（arXiv:2602.20191）。该框架通过观察令牌级别的敏感度差异，实现了在运行时动态调整量化精度，解决了传统量化参数与特定精度绑定导致的切换难题，显著提升了 LLM 部署的灵活性。
原文：MoBiQuant: Mixture-of-Bits Quantization for Token-Adaptive Elastic LLMs
