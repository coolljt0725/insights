Linux 内核社区热点与趋势

内核发布大规模稳定版更新，修复 Fragnesia 等安全漏洞
Kernel.org 近日发布了包括 7.0.10、6.18.33、6.12.91 在内的一系列稳定版内核更新。其中 7.0.10 版本包含了超过 1100 个提交，规模巨大；而 6.1.174 等旧版本则主要针对名为“Fragnesia”的网络分片相关安全漏洞进行了紧急修复。这些更新旨在提升系统的整体稳定性，并应对近期发现的严重网络协议栈安全威胁。

Linux 内核面临网络协议栈安全趋势挑战
近期出现的 Dirty Frag、Copy Fail 和 Fragnesia 等一系列漏洞引发了社区对 Linux 网络协议栈安全性的担忧。这些漏洞主要集中在处理数据包分片和内存拷贝的逻辑中，可能导致拒绝服务或远程代码执行。安全专家指出，这种漏洞频发的趋势预示着内核在处理复杂网络流量时仍存在深层次的架构风险。
原文：Dirty Frag, Copy Fail, Fragnesia: A Worrisome Linux Security Trend

ModuleJail：主动收缩内核模块攻击面
ModuleJail 是一项旨在增强 Linux 内核安全性的新技术，通过限制内核模块的加载和运行环境来减少潜在的攻击路径。该工具可以主动识别并隔离不必要的模块行为，从而在漏洞被利用前提供预防性保护。这对于需要高安全等级的生产环境来说，是防御内核级恶意软件的重要手段。
原文：Modulejail: Proactively shrink a Linux host's kernel-module attack surface

Greg Kroah-Hartman 重申 Rust 对 Linux 内核的重要性
内核维护者 Greg Kroah-Hartman (GKH) 在最近的访谈中再次强调，“Rust 将拯救 Linux 内核”。他认为，通过引入 Rust 语言的内存安全特性，可以从根本上消除驱动程序和核心组件中常见的内存错误。这一表态进一步坚定了社区将 Rust 集成到内核开发主流流程中的信心。

云原生领域

Kubernetes v1.36 声明式校验功能正式商用 (GA)
在 Kubernetes v1.36 中，原生类型的声明式校验（Declarative Validation）已达到 GA 阶段。该功能允许开发者通过简单的声明而非编写数千行手动校验代码来定义 API 规则，显著提升了 API 的可靠性和可维护性。这一改进还为未来通过 OpenAPI 发布校验规则以及与 Kubebuilder 等生态工具集成铺平了道路。
原文：Kubernetes v1.36: Declarative Validation Graduates to GA

Kubernetes v1.36 引入基于清单的准入控制（Alpha）
为了解决准入策略可能被误删或在集群启动初期失效的问题，Kubernetes v1.36 引入了基于清单的准入控制。该功能允许将准入 Webhook 和基于 CEL 的策略定义为磁盘文件，由 API 服务器在启动时直接加载。这种方式确保了策略在 API 服务器处理任何请求之前就已经生效，增强了集群的引导安全性。
原文：Kubernetes v1.36: Admission Policies That Can't Be Deleted

Kubernetes v1.36 增强内存 QoS 分级保护
SIG Node 宣布在 Kubernetes v1.36 中对内存 QoS 功能进行了重要更新，利用 cgroup v2 控制器为内核提供更精准的容器内存处理指导。新版本引入了选择性内存预留、按 QoS 类别进行的分级保护以及增强的可观测性指标。这些改进有助于防止关键应用因内存压力被错误杀掉，提升了多租户环境下的系统稳定性。
