Linux 内核社区热点与趋势

Linux 7.4 合并窗口开启，FAT32 性能获得惊人提升
Linux 7.4 内核合并窗口近日开启，其中最引人注目的改进是 FAT32 文件系统的性能优化，在某些场景下性能提升高达 265 倍。此外，该版本还引入了 RISC-V 架构的便携式性能优化、F2FS 文件系统的多粒度时间戳支持，以及 KSMBD 内核 SMB 服务器的多项增强。这些改动标志着 Linux 在兼容旧文件系统的同时，持续在现代硬件架构上发力。
原文：FAT32 File-System Seeing As Much As 265x Improvement With Linux 7.4

严重 TCP 漏洞 CVE-2026-98432 影响 Linux 内核及 Go 程序
研究人员披露了一个编号为 CVE-2026-98432 的 Linux 内核 TCP 栈释放后重用（Use-After-Free）漏洞。由于 Go 语言程序默认启用了 MPTCP（多路径 TCP），这使得大量 Go 应用暴露在该风险之下。目前社区已发布补丁验证方案，建议系统管理员和开发者尽快检查内核版本并应用安全更新。
原文：Critical TCP use-after-free: CVE-2026-98432

内核社区探讨将容器作为一级内核对象
长期以来，Linux 内核并没有原生的“容器”抽象，而是通过命名空间、控制组等组件组合实现。开发者 Josef Bacik 近期提出了一项名为“Cells”的新概念，尝试将容器转化为内核识别的一级对象。这一尝试旨在简化容器的管理逻辑，虽然过去类似的努力多次失败，但“Cells”方案再次引发了社区对内核容器化架构的深度讨论。
原文：Containers as a recognized kernel object

Linux 7.4 引入多项网络驱动与硬件加速改进
在 Linux 7.4 的网络子系统更新中，引入了硬件步调卸载（Hardware Pacing Offload）功能和大量新的有线/无线网卡驱动。这些改进旨在降低 CPU 在处理高带宽网络流量时的负载，并提升整体网络吞吐性能。这对于高性能计算和云数据中心环境中的 Linux 服务器具有重要意义。
原文：Linux 7.4 Networking Brings Hardware Pacing Offload, New Drivers & More Performance
