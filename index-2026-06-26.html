Linux 内核社区热点与趋势

Linux 扩展缓存感知调度显著提升 MySQL 性能
Linux 内核近期引入的“缓存感知调度”（Cache Aware Scheduling）在最新补丁集中得到了进一步扩展。该技术通过优化 CPU 缓存利用率，在 MySQL 等数据库负载下表现出惊人的性能提升，测试数据显示其吞吐量增幅最高可达 360%。这一改进标志着 Linux 内核在处理高并发、内存密集型应用时的调度策略迈上了新台阶。
原文：Linux Cache Aware Scheduling Extended For Even Better Performance: Up To 360% In MySQL

Linux 7.2 内核引入分配令牌与 bootpatch-SLR 增强安全性
即将发布的 Linux 7.2 内核将集成多项硬化技术，旨在使内核漏洞更难被利用。其中，“分配令牌”（allocation tokens）改变了动态分配结构的内存布局以防止覆盖，而 “bootpatch-SLR” 项目则致力于在启动时随机化结构布局。这些底层改动反映了社区从单纯修复漏洞转向系统级防御的长期趋势。
原文：Hardening the kernel with allocation tokens and bootpatch-SLR

Linux 7.2 清理陈旧驱动：移除 1998 年移植的 PROFIBUS 支持
Linux 7.2 继续执行移除过时硬件驱动的策略，本次被清理的是已多年无人维护且无活跃用户的 PROFIBUS 驱动。该驱动最初于 1998 年从 SCO Unix 移植而来，其移除有助于精简内核源码树并降低维护负担。此外，Realtek RTL8723BS 等长期处于暂存区（Staging）的驱动也正在经历大规模的代码清理。
原文：Linux 7.2 Drops Ancient PROFIBUS Driver

KSMBD 在 Linux 7.2 中新增 SMB2 压缩支持
作为内核集成的 SMB3 文件服务器，KSMBD 在 Linux 7.2 中引入了对 SMB2 协议压缩的支持。这一特性能够显著减少网络传输中的数据量，提升文件共享的效率，尤其是在带宽受限的存储网络环境中。
