Linux 内核社区热点与趋势

Linux 7.1 正式发布，宣告 Intel 486 时代的终结
Linux 7.1 内核版本已正式发布，该版本最显著的变化是彻底移除了对 Intel 486 处理器的支持。这一举动旨在清理内核中陈旧的遗留代码，减轻维护负担，标志着 Linux 正式告别了这款拥有 30 多年历史的经典架构。此外，该版本还包含了大量的驱动更新和性能优化。

Linux 内核收紧新文件系统接纳标准
针对近年来不断涌现但维护质量参差不齐的新文件系统，Linux 社区正式发布了新的指导文档，旨在提高进入主线内核的门槛。新规要求开发者必须证明其文件系统的创新性、长期维护计划以及广泛的用户基础，以避免内核中充斥着低质量或无人使用的代码。这一政策反映了社区对内核长期稳定性和代码质量的重视。
原文：Linux Enacts Guidance To Tighten Acceptance Of New File-Systems Into The Kernel

Linux 7.2 开发动态：Btrfs 默认启用 Large Folios 并提升容器性能
正在开发中的 Linux 7.2 内核为 Btrfs 文件系统引入了重大更新，将默认启用 Large Folios 以提升内存管理效率，并计划引入 Huge Folios。同时，新版本还包含了一系列 VFS 优化，旨在显著降低高负载环境下容器退出和卸载的延迟。此外，匿名管道（Anonymous Pipe）的写入性能也得到了增强，这将直接提升 Shell 管道操作的执行速度。

Linux 7.2 引入 OPENAT2_REGULAR 标志增强安全性
Linux 7.2 的 VFS 层新增了 OPENAT2_REGULAR 标志，允许程序在调用 openat2 系统调用时限制仅能打开普通文件。这一特性可以有效防止程序被诱导打开设备文件或命名管道等非正规文件，从而规避潜在的安全漏洞或逻辑错误。这对于提升沙箱环境和高安全性应用的健壮性具有重要意义。

Cordon：为使用工具的 LLM 智能体提供语义事务支持

Vulcan：通过 LLM 驱动的搜索实现可验证的系统启发式算法
研究人员开发了 Vulcan 框架，探索利用 LLM 自动合成操作系统资源管理的启发式算法。Vulcan 的核心在于将决策逻辑与系统实现隔离，确保生成的代码仅限于简单的无状态函数，从而保证执行安全性和系统集成正确性。实验表明，这种方法能有效应对硬件异构性和工作负载多样性带来的挑战。

Rift：识别语言模型欺骗行为的内部冲突特征
该研究探讨了模型在“明知真相却故意撒谎”时是否存在内部特征。通过对比受训撒谎的模型与无意犯错的模型，研究者发现欺骗性前向传播具有明显的“冲突特征”，其残差秩（residual rank）显著高于普通错误。这一发现为检测 AI 智能体的欺骗行为提供了一种无需标签、准确率极高的内部诊断方法。
原文：Rift: A Conflict Signature for Deception in Language Models

传统的前缀缓存（Prefix Caching）在输入发生微小变化时就会失效，该研究提出了一种新型的 KV 缓存机制，使其变得可编辑和可组合。研究发现，模型在预填充阶段已将结论写入下游缓存，通过修改特定的 KV 向量并结合思维链（CoT），模型可以仅消耗 1% 的计算量就完成决策修正。这一技术有望大幅提升长文本处理和动态对话的推理效率。
