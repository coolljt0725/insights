Linux 内核社区热点与趋势

XFS 文件系统曝出本地提权漏洞 RefluXFS
安全研究机构 Qualys 发现了 Linux 内核 XFS 文件系统中的一个严重漏洞（CVE-2026-64600），该漏洞源于 reflink 操作中的竞态条件。攻击者可以利用该漏洞实现从普通用户到 root 权限的提升。目前该漏洞已被命名为 RefluXFS，社区正紧急发布补丁以修复这一影响广泛的本地提权风险。

内核核心维护者 Greg Kroah-Hartman 在近期采访中表示，Rust 语言不仅提高了内核的安全性，还让内核开发重新变得「有趣」。他指出，随着 C 语言开发中内存安全问题的持续存在，转向 Rust 是 Linux 保持长期生命力的关键一步。这一表态进一步巩固了 Rust 在内核社区中的地位，尽管目前仍存在一些工具链和兼容性方面的讨论。
