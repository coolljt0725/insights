Linux 内核社区热点与趋势

Linux 7.3 计划引入 FailFS 并移除过时的 FreeVxFS 驱动
Linux 内核在 7.3 版本中将迎来文件系统驱动的更替。一方面，内核将引入名为 FailFS 的伪文件系统，它是 NULLFS 的兄弟项目，旨在模拟文件系统故障以进行测试；另一方面，内核计划移除 FreeVxFS 驱动，该驱动此前用于支持 HP-UX 和 SCO UnixWare 的 Veritas VxFS 文件系统只读访问，因维护停滞而被清理。这一动向体现了内核社区在加强测试能力的同时，持续清理陈旧、无维护代码的趋势。
原文：Linux 7.3 Expected To Drop The FreeVxFS File-System Driver | Linux 7.3 Looks Like It Will Upstream FailFS

内核维护者提议恢复 memory.h 头文件以增强兼容性
Linux 手册页（man-pages）维护者近期提议将 memory.h 从“死亡”状态中恢复。该头文件在历史上曾被广泛使用，但在现代标准中常被 string.h 取代，导致一些老旧代码在现代 Linux 环境下编译困难。此举旨在通过恢复该头文件来提高对历史遗留软件的兼容性，减少开发者的迁移负担。

即将到来的 Linux 7.3 合并窗口包含多项硬件支持更新。针对 AMD Kaveri 和 Hawaii 等 GFX7 架构的旧款 GPU，内核引入了改进的软重置（Soft Reset）恢复机制，以提升系统稳定性。此外，内核网络子系统已排队支持 MCTP-over-USB v1.1 协议，该协议主要用于服务器硬件的崩溃转储、日志记录和固件更新等管理任务。
