Linux 7.3 内核在启用 Rust 支持时默认禁用 RandStruct 安全特性
RandStruct 是一项通过随机化内核敏感结构体布局来抵御攻击的安全特性。然而在 Linux 7.3 中，如果内核配置中开启了 Rust 支持，该特性将默认关闭。这反映了在引入 Rust 提高内存安全性的同时，内核社区在处理 Rust 与现有 C 语言安全增强机制的兼容性上仍面临权衡。
