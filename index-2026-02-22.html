Linux 内核社区热点与趋势

Linux 内核开始为 PCIe 7.0 标准做早期准备
尽管 PCIe 6.0 设备尚未大规模普及，Linux 内核已经开始合并支持 PCIe 7.0 的早期补丁。这些补丁主要涉及数据速率定义和链路能力的识别，旨在为未来每秒 128 GT 的超高带宽硬件打下基础。这标志着 Linux 在支持下一代高性能计算和数据中心互连方面继续保持领先地位。
原文：Linux Begins Seeing Early Preparations for PCIe 7.0

Rust 在 Linux 7.0 中脱离“实验性”状态并迈向 1.95 版本
在 Linux 7.0 合并窗口期间，内核社区正式宣布将 Rust 支持视为稳定特性，不再标记为实验性功能。最新的补丁集已经开始为即将发布的 Rust 1.95 版本做准备，进一步巩固了 Rust 作为内核驱动开发第二语言的地位。这意味着开发者可以更放心地在生产级内核代码中使用 Rust 语言。
原文：Linux 7.0 Makes Preparations For Rust 1.95

Linux 7.0 在 AMD EPYC 处理器上展现显著的 PostgreSQL 性能提升
早期的基准测试显示，Linux 7.0 内核在 AMD EPYC "Turin" 服务器上运行 PostgreSQL 数据库时，性能较旧版本有明显增长。这主要归功于内核在调度器、内存管理以及 I/O 路径上的持续优化。对于依赖高性能数据库的数据中心而言，这一升级将带来直接的吞吐量收益。
原文：Linux 7.0 Shows Significant PostgreSQL Performance Gains On AMD EPYC

内核引入虚拟交换空间以现代化交换子系统
为了解决长期以来交换（Swap）子系统在性能和灵活性上的局限，内核引入了“虚拟交换空间”概念。该方案通过统一的虚拟结构替代了旧有的交换表和交换映射，旨在提高内存回收效率并更好地支持现代大内存系统。这一改进对于高负载下的系统稳定性具有重要意义。
原文：Modernizing swapping: virtual swap spaces
