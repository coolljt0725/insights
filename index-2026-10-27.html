Kubernetes v1.37 发布：内存 QoS 功能正式进入 Beta 阶段并默认启用
在 Kubernetes v1.37 中，内存服务质量（Memory QoS）功能已毕业至 Beta 阶段，并在运行 cgroup v2 的 Linux 节点上默认开启。该特性利用内核内存控制器为容器提供更精准的内存预留和限制指导，有效防止节点因内存压力导致的 OOM 连锁反应。这对运行大规模、高密度负载的集群管理员来说是一个重要的稳定性增强。

MEERKAT：将硬件加速器作为异构系统中的一等计算公民
来自 arXiv 的研究指出，现代操作系统（如 Linux）仍将硬件加速器（HA）视为外设而非核心计算单元，导致了巨大的软件开销（OS Taxes）。研究团队构建了 MEERKAT 系统，通过重新设计 OS 抽象，显著降低了加速器在通信、中断处理和调度方面的延迟。该工作证明了通过 OS 层面的深度支持，可以大幅释放异构 SoC 的性能潜力。
原文：Operating System Support for Accelerators as First-Class Compute Elements in Heterogeneous Systems

AaOS：将 LLM 智能体视为操作系统进行安全分析
研究人员提出“智能体即操作系统”（Agents as Operating Systems, AaOS）的概念，认为当前的 LLM 智能体已具备读写文件、启动进程等 OS 核心功能。然而，这些智能体往往以最高权限（Ring 0）运行，缺乏传统 OS 积累了五十年的安全保护机制。该论文通过映射 116 种 OS 机制，分析了当前智能体架构在隔离和权限控制方面的严重缺陷。
原文：Ring-0 by Default: Agents as Operating Systems (AaOS)

ClawMMU：为有状态 LLM 智能体设计的保护一致性虚拟内存
针对 AI 智能体容易受到网页指令注入攻击的问题，研究者提出了 ClawMMU 保护层。该机制为内存中的每一条信息标注来源、所有权和权限等级，并在信息进入模型上下文或调用工具时进行强制检查。其核心原则是“权限可以提升，但权限不能自我提升”，从而将复杂的 AI 攻击转化为经典的计算机保护问题。
原文：ClawMMU: Protection-Coherent Virtual Memory for Stateful LLM Agents

Qurator：跨异构云提供商的量子-经典混合工作负载调度器
Qurator 是一款新型调度器，旨在优化量子-经典混合任务在不同云平台（如 IBM, IonQ 等）上的排队时间和电路保真度。它将混合负载建模为具有显式量子语义的动态有向无环图（DAG），并引入了统一的对数成功评分系统来协调不同硬件的校准数据。实验表明，Qurator 能有效提升量子计算在异构云环境下的执行效率。
原文：Qurator: Scheduling Hybrid Quantum-Classical Workflows Across Heterogeneous Cloud Providers
