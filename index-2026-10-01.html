学术界最新研究

StateFork：为 AI Agent 探索设计的可分支基础设施
针对 AI Agent 在使用计算机任务中修改外部环境状态的问题，研究者提出了 StateFork 逻辑控制平面。它通过将会话、命令和快照操作与底层执行环境分离，允许 Agent 在中间点高效地创建分支、恢复状态或丢弃无效路径。这一机制解决了 Agent 在探索多条任务轨迹时物理状态同步的难题。
原文：StateFork: Branchable Infrastructure for Agent Exploration

ContractWarden：利用 eBPF LSM 在内核层强制执行 AI Agent 的安全边界
为了防止 AI Agent 因提示词注入或规划错误对操作系统造成破坏，ContractWarden 提出了一种基于 Linux 安全模块（LSM）的参考监视器。它通过 eBPF 在内核层强制执行由人类授权的“资产合同”，限制 Agent 的文件和网络访问。该系统不信任 Agent 的策略建议，确保即使 Agent 失控，其破坏行为也会被内核拦截。
原文：ContractWarden: Kernel-Enforced Damage Boundaries for AI Agents via Human-Authorized Contracts

TomasuLLM：AI Agent 的乱序投机执行运行时
受现代处理器乱序执行启发，TomasuLLM 允许 AI Agent 在等待耗时工具（如编译器、测试套件）返回结果时，提前执行后续的工具调用。它在隔离的写时复制（CoW）沙箱中运行这些操作，并在验证前序步骤正确后才按顺序提交结果。实验表明，该方法在不影响任务正确性的前提下，显著降低了 Agent 的端到端延迟。
原文：TomasuLLM: Out-of-Order Speculative Execution for LLM Agents
