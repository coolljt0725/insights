Linus Torvalds 发布了 Linux 7.3-rc7 测试版本，尽管他希望该版本能更小一些，但目前看来没有理由推迟正式发布，预计下周末将迎来 7.3 正式版。值得关注的是，内核本周正式宣布弃用 ext4 文件系统的 data=journal 模式，并计划在 2028 年初将其彻底移除。这一变动反映了内核社区在清理陈旧、低效文件系统特性方面的持续努力。

云原生领域

Kubernetes 节点 Swap 支持正式进入 GA 阶段，助力 AI 负载扩展
Kubernetes v1.34 正式宣布支持节点 Swap 功能（General Availability），这对于内存密集型的 AI 代理负载至关重要。AI 负载在启动时需要巨大内存，但在等待提示词期间内存往往处于闲置状态，通过 NVMe SSD 支持的 Swap，节点可以换出这些闲置内存以容纳更多 Pod。基准测试显示，该功能在 CI/CD 和沙箱化运行环境等场景下能显著提升资源利用率。

学术界最新研究

PredictIO：将工作负载预测与操作系统存储预取解耦
PredictIO 提出了一种新的架构，将复杂的 I/O 预测逻辑从操作系统内核中解耦出来，以应对 LLM 运行时或数据库扫描等复杂负载。传统 OS 预取依赖于简单的偏移量推断，而 PredictIO 允许应用程序提供工作负载感知的策略，同时保持内核对存储资源的统一控制。实验表明，该方法能显著减少存储停顿带来的应用延迟。
原文：PredictIO: Decoupling Workload Prediction from OS-Controlled Storage Prefetching

Ember：让离散显存 GPU 的统一虚拟内存变得实用
针对 GPU 显存不足导致的性能骤降问题，Ember 框架为 NVIDIA 的统一虚拟内存（UVM）引入了混合地址空间管理。Ember 不再依赖低效的缺页中断驱动数据放置，而是通过最小化互连带宽浪费和优化 GPU 利用率，实现了在不修改应用代码的前提下高效处理超量负载。
原文：Ember: Making Unified Virtual Memory Practical for Discrete-Memory GPUs

TEEVisor：在机密虚拟机中启用扩展的 SGX Enclave
该研究提出了 TEEVisor 架构，旨在将 Intel SGX 的进程级隔离与 AMD SEV-SNP 等机密虚拟机（CVM）相结合。通过在 CVM 内部嵌套 Enclave，TEEVisor 解决了 SGX 长期存在的转换开销大、编程模型受限等问题，为云端敏感负载提供了更细粒度的保护和更灵活的部署模式。
