Tutti：利用 SSD 优化长上下文 LLM 推理的 KV 缓存方案
随着 LLM 上下文长度的增加，KV 缓存的体积已远超 GPU 显存容量，导致频繁的 SSD 卸载与加载。研究人员提出了 Tutti，这是一种高效的 SSD 支持的 KV 缓存解决方案，通过消除数据路径中的 CPU 干预来减少 GPU 停顿。该方案利用 GPU 直接存储（GDS）技术，有效解决了由于 GPU 内存布局碎片化导致的大量随机 I/O 瓶颈。
原文：Tutti: Making SSD-Backed KV Cache Practical for Long-Context LLM Serving

原文：Proteo-R1: Reasoning Foundation Models for De Novo Protein Design
