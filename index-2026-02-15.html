Linux 内核社区热点与趋势

Linux 7.0 合并窗口开启，多项性能优化与新特性涌现
Linux 7.0 的合并窗口已经开启，目前已接受超过 7600 个非合并提交。尽管版本号从 6.19 跳至 7.0 更多是基于版本计数的习惯而非重大架构变革，但该版本仍引入了包括 F2FS 文件系统性能优化、Arm 64 字节单拷贝原子指令支持以及多车道 SPI 支持等重要更新。这标志着内核在支持现代硬件特性和提升存储效率方面迈出了新的一步。

F2FS 文件系统在 Linux 7.0 中迎来关键性能提升
闪存友好文件系统（F2FS）在即将发布的 Linux 7.0 内核中引入了多项关键性能优化。这些改进旨在进一步提升固态存储设备的读写效率，并优化了元数据处理逻辑。对于依赖高性能闪存存储的用户和移动设备厂商而言，这将带来更流畅的系统响应体验。

Linux 7.0 引入 ML-DSA 抗量子签名算法支持
为了应对未来量子计算对传统加密体系的威胁，Linux 7.0 内核正式集成了基于模块格的数字签名算法（ML-DSA）。这是内核加密子系统向抗量子加密（PQC）迈出的重要一步，确保了系统在长效安全通信中的可靠性。该特性的加入反映了内核社区对前沿安全标准的高度关注。
原文：Linux 7.0 Lands ML-DSA Quantum-Resistant Signature Support

内核撤回“可撤销资源管理”补丁系列
原计划在 Linux 7.0 中合并的“可撤销（revocable）资源管理”补丁系列因发现潜在问题而被临时撤回。该系列补丁旨在解决瞬态设备（如热插拔设备）消失时内核数据结构的生命周期管理难题。社区决定推迟合并以进行更深入的测试和设计调整，这体现了内核开发中稳定性优先的原则。

Linux 7.0 增强对 Arm 架构与新型硬件的支持
Linux 7.0 增加了对 Arm 64 字节单拷贝原子指令（LS64/LS64V）的支持，这将显著提升高性能计算场景下的同步效率。此外，HID 子系统也进行了更新，增加了对 PS4/PS5 版《摇滚乐队 4》吉他控制器以及多种新型笔记本电脑特性的支持。这些更新展示了 Linux 内核在专业外设和最新处理器指令集方面的广泛兼容性。
