GNStor：面向 GPU 原生的高性能远程全闪存阵列设计
针对现有 GPU 存储系统中 CPU 参与 I/O 导致的性能瓶颈，研究者提出了 GNStor。该设计实现了 GPU 原生的远程 I/O 请求编排和元数据管理，消除了 CPU-GPU 交互开销。实验表明，这种 GPU 为中心的设计能显著提升端到端的 I/O 性能，适用于大规模数据密集型应用。
原文：GNStor: Design of GPU-Native High-Performance Remote All-Flash Array

LiftQuant：通过维度提升与投影实现连续位宽的 LLM 量化
传统的 LLM 量化受限于整数位宽（如 2-bit、3-bit），难以精确匹配特定的内存预算。LiftQuant 引入了一种“提升再投影”机制，通过在高维空间投影 1-bit 格点来近似低维权重向量，从而实现准连续的位宽控制。这种方法允许开发者根据硬件资源实现真正的帕累托最优部署。
原文：LiftQuant: Continuous Bit-Width LLM via Dimensional Lifting and Projection

StepPRM-RTL：通过逐步过程奖励引导 LLM 生成硬件描述代码
自动生成 RTL 代码（如 Verilog）面临长程推理和严格正确性的挑战。StepPRM-RTL 框架结合了逐步轨迹建模和过程奖励模型（PRM），为 LLM 提供细粒度的反馈。这种方法显著增强了模型在硬件设计中的推理忠实度和功能正确性，为自动化芯片设计提供了新思路。
原文：StepPRM-RTL: Stepwise Process-Reward Guided LLM Fine-Tuning for Enhanced RTL Synthesis
