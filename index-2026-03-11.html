学术界最新研究

Pichay：为 LLM 上下文窗口引入请求分页机制
来自 arXiv 的研究指出，当前的 LLM 上下文窗口更像 L1 缓存而非内存，缺乏虚拟内存管理导致了严重的资源浪费。研究者提出了 Pichay 系统，通过透明代理拦截消息流，实现对陈旧内容的换出（Evict）和按需换入（Paging）。实验显示，该系统能有效减少约 21.8% 的结构性 Token 浪费。
原文：The Missing Memory Hierarchy: Demand Paging for LLM Context Windows

原文：AgentOS: From Application Silos to a Natural Language-Driven Data Ecosystem

FlexServe：基于 ARM TrustZone 的移动端 LLM 安全推理系统
针对移动设备上 LLM 模型权重和用户隐私易受攻击的问题，研究者开发了 FlexServe。该系统利用 ARM TrustZone 硬件隔离技术保护推理过程，并通过灵活的资源隔离机制克服了 TrustZone 在内存和 NPU 调用上的高开销。这为在智能手机上实现高性能且安全的私有化 AI 部署提供了技术路径。
原文：FlexServe: A Fast and Secure LLM Serving System for Mobile Devices

研究人员识别出 MoE 架构在解码阶段面临的结构性劣势：专家路由导致的微批次碎片化以及巨大的参数量对 KV 缓存空间的挤压。论文提出了 qs 不等式，作为一个预测准则来识别 MoE 何时在性能上逊色于同质量的稠密模型。该研究为大模型架构的选择提供了量化的理论依据。
