Linux 内核 iomap 层深度解析：简化文件系统与存储映射

bpfix：弥合 eBPF 验证器拒绝诊断的鸿沟
研究人员对 235 个 eBPF 程序被验证器拒绝的案例进行了实证研究，发现近一半的错误仅返回模糊的 EINVAL 代码，导致开发者难以定位根因。为此，他们开发了 bpfix 工具，能够重建验证失败时的逻辑证明路径，帮助开发者精准识别程序失去验证器信任的位置。该研究显著提升了 eBPF 开发的可观测性和调试效率。
原文：Characterizing and Bridging the Diagnostic Gap in eBPF Verifier Rejections

Elastic Gang：针对 OS 进程共存的 LLM 推理弹性调度机制
在移动端或边缘设备上运行 LLM 推理时，计算密集型的 SIMD 任务常与 OS 其他进程争抢核心。论文提出了 Elastic Gang 机制，并在基于 Rust 的 Anima OS 中实现，允许推理任务的成员核心在每生成一个 Token 之间动态变化。通过一种基于 Epoch 的锁定协议，该系统在不导致死锁或数据损坏的前提下，实现了推理任务与系统任务的高效并发。
原文：Elastic Gang: Per-Token Membership Change for a Hard-Barriered LLM Inference Gang Co-Scheduled with OS Processes

kAgent：利用执行引导的 AI 代理自动修复 Linux 内核崩溃
针对 syzkaller 等工具发现的大量内核崩溃问题，研究者开发了 kAgent 代理。不同于通用的代码修复模型，kAgent 专门针对内核代码的底层特性进行了优化，能够利用执行反馈来验证修复方案的有效性。在实验中，该代理展现了处理缺乏自然语言描述、高度专业化的内核崩溃日志的强大能力。
原文：kAgent: An execution-guided crash resolution agent for the Linux kernel

ProbeLogits：AI 原生操作系统中的内核级 LLM 推理原语
该研究提出在操作系统内核中直接运行 LLM 推理，利用模型自身的 Logit 分布作为治理原语。通过 ProbeLogits 操作，内核可以在文本生成前读取特定 Token 的概率，从而以极低的成本判断智能体的行为是否安全。这种“内核驻留”的安全检查机制避免了用户态脚本被绕过的风险，为 AI 原生系统提供了坚实的安全底座。
原文：ProbeLogits: Kernel-Level LLM Inference Primitives for AI-Native Operating Systems
