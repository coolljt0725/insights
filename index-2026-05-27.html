学术界最新研究

LearnedCache：集成 eBPF 与感知器的 Linux 页面缓存替换策略
研究人员开发了 LearnedCache，这是一种利用 eBPF 技术集成到内核中的单层感知器缓存替换算法。该研究打破了传统页面缓存依赖启发式规则（如 LRU）的局限，通过机器学习动态适应多变的负载模式。实验表明，这种方法在减少磁盘访问和提升应用性能方面具有显著潜力，且保持了极低的内核开销。
原文：LearnedCache: An eBPF-Integrated Perceptron-Based Eviction Policy for the Linux Page Cache

Sandlock：利用非特权 Linux 原语约束 AI 智能体代码执行
针对 AI 智能体运行不可信代码的安全风险，Sandlock 提出了一种轻量级的进程沙箱方案。它利用 Linux 原语将静态策略编译为内核强制规则，同时通过微型监控器处理运行时决策。相比容器或微型虚拟机，Sandlock 在保持极低启动成本的同时，提供了更细粒度的系统调用控制。
原文：Sandlock: Confining AI Agent Code with Unprivileged Linux Primitives

GEM：基于几何熵混合的 LLM 数据筛选优化框架
论文提出了 GEM 框架，将 LLM 预训练的数据筛选问题重新定义为超球体上的变分问题。通过引入混合平衡正则化项，GEM 有效解决了传统聚类方法中的“聚类坍塌”问题，能够发现隐藏的语义结构。这种方法在不增加数据总量的前提下，显著提升了模型预训练的效率和最终性能。
原文：GEM: Geometric Entropy Mixing for Optimal LLM Data Curation

InfoQuant：面向低比特 LLM 量化的激活分布整形技术
针对低比特量化中激活值离群点导致的精度损失，InfoQuant 提出了一种面向分立化设计的激活转换方法。研究分析了什么样的激活分布更易于被量化器处理，并通过数学手段对分布进行整形。该技术为在资源受限设备上部署高性能、低功耗的 LLM 提供了新的理论支撑。
原文：InfoQuant: Shaping Activation Distributions for Low-Bit LLM Quantization

原文：The Constraint Tax: Measuring Validity-Correctness Tradeoffs in Structured Outputs
