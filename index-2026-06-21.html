Linux 内核社区热点与趋势

Linux 内核正式移除 strncpy API，历时六年完成清理
经过长达六年的努力和超过 360 个补丁的迭代，Linux 7.2 内核终于彻底移除了长期被弃用的 strncpy 函数。该 API 因其在处理字符串结尾和缓冲区溢出方面的潜在风险，一直被视为安全隐患，社区通过逐步替换为更安全的 strscpy 等接口，显著提升了内核代码的健壮性。这一里程碑式的清理工作标志着内核在消除历史遗留安全漏洞方面取得了重大进展。

ARM32 架构引入 NEON 加速的 CRC64 代码，性能提升显著
在 Linux 7.1 中为 ARM64 引入的 NEON 加速 CRC64-NVMe 支持，现在已被适配并合并至 Linux 7.2 的 32 位 ARM 架构中。该优化利用 NEON 指令集将校验和算法的性能提升了约 6 倍，解决了 NVMe 及其他存储子系统在数据校验时的性能瓶颈。这对于仍在使用 32 位 ARM 设备的工业和嵌入式场景来说，是一个重要的效率提升。
原文：Linux's ARM64 NEON Intrinsics CRC64 Code Adapted To Work On 32-bit ARM

exFAT 文件系统通过 IOmap 转换实现性能优化
Linux 7.2 内核对 exFAT 文件系统进行了重要改进，将其迁移到了 IOmap 基础架构之上。这一改动由三星工程师兼维护者 Namjae Jeon 推动，旨在通过更现代的 I/O 映射机制提升文件系统的读写效率。对于广泛使用 exFAT 格式的可移动存储介质而言，用户将在 Linux 环境下获得更流畅的数据传输体验。
原文：exFAT File-System Enjoys Better Performance On Linux 7.2 With IOmap Conversion
