Linux 内核社区热点与趋势

Linux 7.2 正式版发布，引入多项性能优化与新特性
Linus Torvalds 正式发布了 Linux 7.2 稳定版内核。该版本包含多项重大更新，如 BPF 系统调用的通用属性支持、针对 CPU 调度器的缓存感知负载均衡、Btrfs 文件系统的大页面（large-folio）支持，以及 Landlock 安全模块的增强。尽管 AI 时代带来的补丁提交量激增，该版本仍按计划发布，并将为即将到来的 Ubuntu 26.10 等发行版提供动力。
原文：Linux 7.2 Released With Faster I/O, New AMD & Intel Driver Improvements

Linux 7.3 将允许通过 BPF 程序动态选择执行环境
在即将到来的 Linux 7.3 合并窗口中，内核的 binfmt_misc 功能将得到扩展。这项改进允许内核通过挂载 BPF 程序，在执行二进制文件时动态匹配并决定其解释器（如 Wine 或 Java 运行时）。这种可编程性为处理非原生格式文件提供了更高的灵活性，能够根据每个执行请求实时确定最佳运行环境。
原文：Linux 7.3 binfmt_misc To Allow BPF Programs To Dynamically Choose Execution Environments

Google 工程师提交 AVX-512 优化补丁，大幅提升 Linux RAID 性能
来自 Google 的工程师 Eric Biggers 近期更新了针对 Linux RAID 的 AVX-512 优化补丁。测试数据显示，在现代 AMD Ryzen 9 9950X (Zen 5) 处理器上，优化后的 xor_gen() 函数可带来高达 43% 的性能提升。该代码目前已更新至第四版，有望在未来的内核版本中合并，显著增强现代 CPU 在存储冗余计算方面的效率。
原文：AVX-512 xor_gen Continues To Look Exciting For Helping Linux RAID With Modern CPUs

Linux 7.2 紧急引入 tlbi= 启动选项以优化 x86 性能
在 Linux 7.2 正式发布前的最后时刻，内核合并了一个紧急补丁，新增了 tlbi= 启动参数。该选项允许用户手动控制 x86 架构下的 TLB（转换后备缓冲区）刷新策略，旨在解决特定硬件环境下的性能瓶颈或兼容性问题。这反映了内核社区在处理复杂硬件交互时，倾向于提供更多底层调优手段的趋势。
原文：tlbi= Boot Option Submitted Ahead Of Linux 7.2 Kernel Release

Presto：面向太比特时代的匹配-动作（Match-Action）TCP 协议栈
研究人员提出了 Presto，这是首个在可编程 RMT 流水线上实现 ASIC 级性能的 TCP 协议栈。Presto 通过乐观并发控制、伪段注入和“线缆中”处理等创新技术，克服了 TCP 复杂状态更新与 RMT 单向执行模型之间的矛盾。该系统在保持标准 TCP 语义和 POSIX 兼容性的同时，提供了极高的能效和吞吐量。
原文：Presto: A Match-Action TCP Stack for the Terabit Era

Agent-Native 文件系统：解决 AI Agent 对文件系统的误操作风险
针对 AI 编程 Agent 经常误删文件或泄露密钥的问题，本文提出了“Agent 原生文件系统”的概念。研究者建议将信息感知和控制权从 Agent 转移到文件系统层，引入效果内省、变更撤销和访问门控三大原语。这使得 Agent 能够自主纠错，同时在敏感操作时保留用户交互，提升了 Agent 操作的安全性。

CoRun：通过填充实现简单高效的确定性 LLM 推理
LLM 推理由于 GPU 执行的批处理依赖性，往往表现出输出不一致的问题。CoRun 系统观察到，尽管大多数内核不是批处理不变的，但它们是位置不变的。通过基于调度的填充策略，CoRun 在不显著增加延迟的情况下实现了确定性推理，解决了模型评估和强化学习中的输出一致性难题。
原文：CoRun: Padding is Simple and Efficient for Deterministic LLM Inference
