Linux 内核社区热点与趋势

Linux 7.0 引入更安全的 kmalloc() 内存分配 API
Linux 内核在 7.0 合并窗口期间引入了由 Kees Cook 开发的大规模安全增强功能，涉及超过 8000 个文件和 20000 行代码。该更新通过引入类型安全的内存分配函数，旨在从根源上减少因缓冲区溢出和类型不匹配导致的内核安全漏洞。这一变动虽然规模巨大，但通过自动化的重构工具确保了 API 的易用性和系统的稳定性。
原文：A safer kmalloc() for 7.0

Linux 7.1 将正式退役 UDP-Lite 协议以优化网络栈性能
内核社区决定在即将到来的 Linux 7.1 版本中移除对 UDP-Lite 协议的支持，该协议自 2.6.20 版本引入以来一直允许交付部分损坏的数据包。由于该协议在现代应用中极少使用且存在长期未修复的缺陷，移除它可以显著简化网络子系统的代码逻辑。这一举措不仅能减少内核的维护负担，还能为非 UDP-Lite 用户带来微小的性能提升。
原文：Linux 7.1 To Retire UDP-Lite - Allows For Better Performance With Cleansed Code

可扩展调度器 sched_ext 增加 SCX_ENQ_IMMED 特性
在 Linux 7.1 的开发周期中，基于 BPF 的可扩展调度器类 sched_ext 引入了名为 SCX_ENQ_IMMED 的新功能。该特性允许开发者更精确地控制任务进入 CPU 运行队列的时机，增强了自定义调度策略的实时响应能力。这标志着 Linux 内核在允许用户态通过 BPF 深度定制调度逻辑方面又迈出了重要一步。
原文：Linux 7.1 sched_ext To Add "SCX_ENQ_IMMED" For Tighter Control When Tasks Land On A CPU
