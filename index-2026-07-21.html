Linux 内核引入 KNOD 技术，实现网络任务直接卸载至 AMD GPU

因性能低下且存在安全隐患，Linux 7.3 将禁用高通加密引擎驱动
Linux 7.3 内核计划禁用高通加密引擎（QCE）驱动程序，原因是该硬件加速器的表现甚至慢于纯 CPU 处理。此外，该驱动长期存在各种 Bug 和竞态条件，可能引发严重的安全漏洞。社区认为维护这样一个“有害”的驱动程序已无必要，此举反映了内核社区在清理低质量、低效驱动方面的果断态度。

Linux 内核修复 UDP 协议栈中的越界写入漏洞
安全研究人员在 Linux 内核的 UDP MSG_SPLICE_PAGES 片段边界处理逻辑中发现了一个越界写入（OOB write）漏洞。该漏洞可能被恶意利用以破坏系统内存，甚至导致权限提升。目前相关修复补丁已在社区流转，提醒广大系统管理员关注后续的安全更新发布。
