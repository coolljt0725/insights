学术界最新研究

Proxics：针对远端内存加速器的高效编程模型
随着 CXL 内存池的兴起，近数据处理（NDP）重新受到关注。Proxics 提出了一种基于虚拟处理器和 IPC 通道的 OS 抽象，旨在解决 NDP 硬件处理能力弱、传统进程模型过于沉重的问题。该模型为远端内存加速器提供了简洁且可移植的编程接口。
原文：Proxics: an efficient programming model for far memory accelerators

GPUOS：实现透明算子融合的 GPU 操作系统原语
现代深度学习负载中，频繁的小算子启动开销已成为瓶颈。GPUOS 提出了一种持久化内核架构，通过运行时 JIT 编译和函数指针注入，在单个长寿命 GPU 内核中连续处理任务。这种设计消除了重复的内核启动开销，显著提升了推理和微批次训练的效率。
原文：GPUOS: A GPU Operating System Primitive for Transparent Operation Fusion

Equilibria：大规模多租户 CXL 内存分层框架
针对超大规模数据中心，Equilibria 解决了一直以来 Linux 在 CXL 内存分层上的局限性。它提供了多租户支持、灵活的控制平面以及强大的可观测性，能够有效处理混合负载并确保性能公平性。该框架有助于降低数据中心的内存成本和功耗。
原文：Equilibria: Fair Multi-Tenant CXL Memory Tiering At Scale

AgenTEE：边缘设备上的机密 LLM 代理执行环境
AI 代理在边缘端执行时面临模型权重泄露和运行时状态被攻击的风险。AgenTEE 利用可信执行环境（TEE）为 LLM 代理提供机密计算保障，保护专有资产和敏感数据。该研究针对边缘设备的异构性进行了优化，平衡了安全性和执行效率。
原文：AgenTEE: Confidential LLM Agent Execution on Edge Devices

Sockeye：用于分析硬件文档的领域特定语言
硬件平台的复杂性给系统程序员带来了巨大挑战，非正式的文档描述往往导致安全漏洞。Sockeye 引入了一种 DSL 来描述硬件语义和安全属性，并成功为 8 个平台创建了机器可读规范。研究者利用该语言正式证明了硬件设计中的内存机密性和完整性问题。
原文：Sockeye: a language for analyzing hardware documentation
