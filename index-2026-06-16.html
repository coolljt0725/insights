Linux 7.1 正式版发布，开发活跃度持续走高
Linus Torvalds 已于 6 月 14 日正式发布 Linux 7.1 内核。这一版本引入了大量新特性，并吸引了众多新开发者参与，标志着内核社区在功能扩展和人才梯队建设上取得了双重进展。LWN 的统计数据显示，该周期的开发节奏保持稳健，社区正通过多样化的贡献者群体维持其创新活力。

Linux 7.2 引入缓存感知调度，大幅提升多缓存架构性能
Linux 7.2 内核已合并缓存感知调度（Cache Aware Scheduling）功能，这对于拥有多个末级缓存（LLC）的现代 Intel 和 AMD 处理器具有重要意义。通过优化调度器对缓存拓扑的感知，新内核能够更有效地分配任务，减少跨缓存访问延迟。这一改进将直接提升多核处理器在复杂负载下的执行效率。
原文：Cache Aware Scheduling Merged For Linux 7.2 For Boosting Modern Intel & AMD CPUs

Linux 7.2 性能大爆发：IOmap 与 /proc/filesystems 获得显著优化
即将到来的 Linux 7.2 内核在文件系统和虚拟文件系统（VFS）层面进行了关键优化。通过调整两行代码，EXT4 和 XFS 在 IOmap 框架下的 IOPS 提升了约 5%；同时，通过优化 /proc/filesystems 的读取逻辑，其访问速度提升了高达 444%。这些底层改进证明了即使是成熟的内核模块，通过精细的代码调整仍能榨取显著的性能红利。
原文：Linux 7.2 Optimization Shows +5% IOPS For EXT4 & XFS After Moving Around Two Lines Of Code

Rust 零拷贝库引入 Linux 7.2，进一步减少“不安全”代码
Linux 7.2 开发分支引入了 Rust Zerocopy 库，旨在通过 Rust 语言特性实现更安全的内存操作。此次更新增加了超过四万行 Rust 代码，重点在于消除内核中潜在的内存安全隐患。这标志着 Rust 在 Linux 内核中的应用正从基础框架搭建转向更深层次的库集成和功能替代。
