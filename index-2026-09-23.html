内核调度器引入缓存感知（CAS）修复程序
Linux 7.3 内核计划合并一组缓存感知调度（Cache Aware Scheduling）的修复补丁，并计划回刷至 7.2 版本。该功能通过将相关任务组合在共享末级缓存（LLC）的 CPU 核心上，有效减少了缓存抖动并降低了延迟。这些修复将进一步优化多核处理器在高负载下的执行效率。

Linux 7.3 将支持通过 sysfs 报告 AMD SEV 状态
Linux 7.3 内核新增了一个便捷的接口，允许用户通过 /sys/devices/system/cpu/sev/sev_status 查看 AMD 安全加密虚拟化（SEV）的状态。此前，获取此类安全状态信息相对繁琐，这一改进为云服务商和安全审计人员提供了更直接的硬件安全验证手段。

Kubernetes v1.37 强化容器存储安全特性
Kubernetes v1.37 版本引入了 emptyDir 权限模式和绑定挂载（bind mount）选项，显著增强了存储安全性。这些功能允许开发者直接在 K8s 配置中禁止在可写卷上执行二进制文件，或防止跨容器的文件删除。这为构建零信任架构的容器环境提供了底层技术支撑。

原文：Kubernetes v1.37: KubeletInUserNamespace (aka Rootless mode) Graduates to Beta

Kubernetes 引入原地 Pod 扩容的调度抢占机制
随着原地 Pod 扩容功能进入 GA，Kubernetes v1.37 进一步引入了配套的调度抢占 Alpha 特性。当运行中的 Pod 请求扩容但节点资源不足时，调度器现在可以尝试通过抢占低优先级 Pod 来腾出空间。这一改进解决了扩容请求因资源碎片化而无限期挂起的问题，提升了资源利用的灵活性。

TierBPF：基于 eBPF 的分层存储页面迁移控制
TierBPF 是一种新型的软件机制，利用 eBPF 挂钩为分层存储系统提供架构感知的页面准入控制。它能够根据页面大小和底层硬件拓扑做出更优的迁移决策，且不依赖于应用程序的工作集大小。该研究为优化异构内存环境下的应用性能提供了轻量级且可定制的方案。
原文：TierBPF: Page Migration Admission Control for Tiered Memory via eBPF
