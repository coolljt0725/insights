Linux 7.1 将引入 FSMOUNT_NAMESPACE 特性
在即将到来的 Linux 7.1 合并窗口中，预计将引入名为 FSMOUNT_NAMESPACE 的新 VFS（虚拟文件系统）功能。该特性旨在增强挂载命名空间的管理灵活性，允许更精细地控制文件系统在不同容器或进程环境中的可见性。这一改进对于提升容器运行时和沙箱系统的隔离性具有重要意义。
原文：FSMOUNT_NAMESPACE Feature Coming For Linux 7.1

RISC-V 架构 BeagleV Ahead 开发板将在 Linux 7.1 中支持 HDMI
开源 RISC-V 单板计算机 BeagleV Ahead 基于四核 TH1520 SoC，其 HDMI 显示支持代码已提交至 Linux 7.1 主线内核。此前该板在主线内核中缺乏图形输出支持，随着设备树（Device Tree）相关补丁的合并，用户将能够直接在主线内核下驱动显示器。这标志着 RISC-V 硬件在桌面和多媒体应用支持方面迈出了坚实的一步。

Kubernetes 引入 Node Readiness 控制器以管理复杂依赖
为了解决节点在启动过程中对网络插件、存储驱动或 GPU 固件等复杂基础设施的依赖问题，Kubernetes 推出了 Node Readiness 控制器。该控制器允许通过声明式系统管理节点污点（Taints），确保只有在所有自定义健康检查通过后，节点才会被标记为“就绪”。这极大地提升了大规模集群中工作负载调度的可靠性。
原文：Introducing Node Readiness Controller

cgroup v1 到 v2 的 CPU 权重转换算法改进
Kubernetes 宣布改进了从 cgroup v1 的 CPU Shares 到 cgroup v2 CPU Weight 的转换公式。由于 v1 使用毫核（millicpu）定义，而 v2 使用 1 到 10000 的权重范围，旧的转换方式在某些场景下会导致优先级分配不均。新的算法解决了这一关键问题，确保了在升级到 cgroup v2 环境时，容器的 CPU 资源分配更加公平和准确。
原文：New Conversion from cgroup v1 CPU Shares to v2 CPU Weight
