CMV：借鉴操作系统虚拟内存机制管理 LLM 上下文
研究者提出了“上下文内存虚拟化”（CMV）系统，将 LLM 积累的理解视为版本控制的状态。该系统借鉴了操作系统的虚拟内存概念，将对话历史建模为有向无环图（DAG），并引入快照、分支和修剪原语。这使得 LLM 代理能够在多个独立会话间高效重用上下文，解决了长程推理中的状态丢失问题。
原文：Contextual Memory Virtualisation: DAG-Based State Management and Structurally Lossless Trimming for LLM Agents

原文：WaveSSM: Multiscale State-Space Models for Non-stationary Signal Attention

原文：Orthogonal Weight Modification Enhances Learning Scalability and Convergence Efficiency without Gradient Backpropagation

因果计算不对称性：通过训练速度识别因果方向
该研究提出了因果计算不对称性（CCA）原则，发现神经网络在真实因果方向（从原因到结果）上的收敛速度明显快于反向。通过建立形式化的数学证明，研究者展示了反向模型由于残差依赖性会面临更高的损失底线和梯度噪声。这一发现为无监督因果发现提供了一种简单而有效的动力学判别方法。
原文：Causal Direction from Convergence Time: Faster Training in the True Causal Direction
