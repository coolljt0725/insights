Linux 7.0-rc3 合并 Intel 与 AMD x86 架构关键修复补丁
本周 Linux 7.0-rc3 合并了一批针对 x86 架构的紧急补丁，重点修复了 Intel 和 AMD 处理器在运行中的稳定性问题。这些补丁涵盖了微代码加载、电源管理以及特定指令集的错误修正，旨在确保新内核在即将发布的正式版中能够稳定支持主流硬件。对于追求极致稳定性的服务器和桌面用户而言，这些底层修复至关重要。

Linux 7.0 引入 epoll 性能优化，提升 AMD Zen 2 处理器效率
Linux 7.0 合并了一项针对事件轮询机制（epoll）的微小性能优化，该优化在 AMD Zen 2 架构处理器上表现尤为明显。epoll 是 Linux 处理高效 I/O 多路复用的核心组件，通过减少文件描述符监控过程中的开销，能够显著提升高并发网络服务的响应速度。这一改进体现了内核社区在成熟子系统上持续挖掘硬件潜力的努力。
原文：Linux 7.0 Adds A New Minor Performance Optimization Shown With AMD Zen 2 CPUs（来源：Phoronix）

LWN 深度探讨 NTP 网络时间协议的安全性挑战与改进
Geoff Huston 在 LWN 发表文章，重新审视了网络时间协议（NTP）在现代分布式系统中的安全风险。由于 NTP 传统上以明文传输，攻击者可能通过伪造服务器响应来干扰客户端时钟，进而破坏 TLS 证书验证、DNSSEC 和云端数据一致性。文章详细讨论了通过 TLS 封装 NTP 或采用更安全的认证机制来保护时间同步服务的必要性。
