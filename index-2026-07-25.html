Ubuntu 26.04 计划移除历史遗留文件 /etc/debian_version
Ubuntu 开发团队正考虑移除长期存在的 /etc/debian_version 文件，该文件最初是从 Debian 继承而来的历史产物。开发者认为该文件目前提供的信息并不准确，且现代 Linux 系统早已将 /etc/os-release 作为读取发行版信息的标准接口。此举标志着 Ubuntu 在进一步理清其与上游 Debian 关系的同时，也在推动系统配置的标准化。
原文：Ubuntu Linux Looking To Get Rid Of /etc/debian_version Historical Artifact

Fedora 45 逐步淘汰内核加密用户空间 API (AF_ALG)
紧随 Linux 内核的弃用计划，Fedora 45 准备逐步关闭 AF_ALG 接口，该接口允许用户空间程序直接调用内核加密 API。社区认为直接在用户空间使用加密库（如 OpenSSL）通常更安全且性能更好，减少内核暴露面有助于提升整体安全性。Fedora 的这一变动将引导开发者转向更现代的加密实现方式。
原文：Fedora 45 Looks To Begin Phasing Out In-Kernel Crypto Userspace API
