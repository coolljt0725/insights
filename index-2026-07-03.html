Linux 6.9 及后续版本存在 LUKS 加密密钥残留内存风险
社区发现自 Linux 6.9 版本以来，LUKS 磁盘加密在系统挂起（Suspend）时不再主动从内存中擦除加密密钥。这意味着如果攻击者能够物理接触处于挂起状态的设备，可能通过冷启动攻击等手段获取密钥。该问题引起了对内核安全回归的担忧，相关开发者正在讨论如何在性能与安全性之间重新取得平衡。

EFS 文件系统将在 Linux 7.3 中被正式移除
在 Linux 内核中存在了 20 多年的 EFS（Extent File System）文件系统驱动程序计划在 7.3 版本中移除。EFS 最初用于 SGI IRIX 系统，但在 Linux 下已超过 20 年无人维护且仅支持只读模式。随着旧硬件支持的逐步清理，内核团队决定移除这些过时的代码以减轻维护负担。
