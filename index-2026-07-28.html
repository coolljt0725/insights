内核社区探讨引入危险指针（Hazard Pointers）以优化 RCU
Linux 内核社区目前正在讨论由 Mathieu Desnoyers 和 Paul McKenney 提交的危险指针实现方案。虽然现有的读取-复制-更新（RCU）机制在内核中应用广泛，但在某些高并发场景下会导致内存占用增加和清理延迟。危险指针作为一种替代的无锁更新方法，有望在特定负载下提供更优的性能表现和更及时的资源回收。

KernelScript：一种用于 eBPF 应用的跨边界类型化领域特定语言
来自 arXiv 的研究提出了一种名为 KernelScript 的 DSL，旨在解决 eBPF 开发中内核代码与用户空间加载器之间类型不一致的问题。KernelScript 允许开发者在一个源文件中定义 Map 和程序句柄，并自动编译为标准 C 代码。实验表明，该语言能有效防止因跨边界类型定义冲突导致的内核状态损坏。
原文：KernelScript: Cross-Boundary Typed DSL for eBPF Applications

Hemlock：一种紧凑且可扩展的互斥锁算法

原文：Hemlock : Compact and Scalable Mutual Exclusion

针对 LLM 编程智能体在处理频繁变动的文件时容易产生“陈旧快照”的问题，论文提出了 CORVUS 架构。该架构通过解耦文件读取动作与其观察结果，维护一个同步的底层状态，避免了智能体在轨迹中重复读取相同文件。这种方法显著减少了上下文窗口的浪费，并降低了推理错误率。
