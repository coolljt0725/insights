Linux 内核社区热点与趋势

Linux 7.2 将引入现代 NTFS 驱动增强与 Windows 原生符号链接支持
在 Linux 7.1 完成了 NTFS 驱动的“复兴”后，即将到来的 7.2 版本将对该驱动进行进一步的加固和修复。此次更新最显著的特性是增加了对 Windows 原生符号链接的支持，这将极大地提升 Linux 与 Windows 分区之间的数据互操作性。这一改进标志着 Linux 内核在处理微软文件系统方面的成熟度迈上了新台阶。

Systemd v261 发布：引入云端实例元数据服务与引导密钥功能
Systemd v261 版本正式发布，带来了多项重量级更新，包括全新的云端“实例元数据服务”（IMDS）子系统。新版本还为缺乏物理 TPM 模块的系统提供了“引导密钥”功能，并支持内核的实时更新编排（LUO）和 Kexec 移交（KHO）系统。这些特性旨在增强 Linux 系统在云环境和嵌入式场景下的自动化管理与安全性。
原文：Systemd v261 released

BPF 程序将支持挂起与恢复：引入协程机制处理长任务
在 2026 年 Linux 峰会上，开发者 Kumar Kartikeya Dwivedi 展示了将 BPF 程序表达为协程的实验性工作。目前 BPF 程序必须在开始的上下文中运行至结束，而新机制允许程序在执行过程中挂起并在稍后恢复。这一变革将显著降低编写长运行 BPF 任务的难度，扩展了 BPF 在复杂内核扩展场景下的应用潜力。

Linux 7.2 针对 Apple M3 芯片及多种 SoC 提供主线支持
Linux 7.2 内核合并了近 1000 个 SoC 相关的补丁，其中最受关注的是初步实现了对 Apple M3 芯片的引导支持。此外，该版本还增加了对五种新型 SoC 的支持，并对 AMD 的音频协处理器（ACP）进行了重大的架构调整。这意味着 Linux 在高性能 ARM 设备和新一代 x86 移动平台上的兼容性得到了大幅增强。

Intel TDX 技术实现无需重启的实时安全更新
针对现代 Intel Xeon 处理器的可信域扩展（TDX）技术在 Linux 7.2 中变得更加实用。新特性允许系统在不重启的情况下应用关键的安全更新，这对于追求极高可用性的机密计算环境至关重要。此举解决了机密计算在安全性与业务连续性之间的权衡难题。
原文：Intel TDX Now Much More Practical With Ability To Apply Important Updates Without Reboot

Linux 6.9 及后续版本被曝 LUKS 加密密钥泄露漏洞
研究发现，自 Linux 6.9 内核以来，LUKS 在挂起状态下未能成功从内存中擦除卷加密密钥。这意味着攻击者可能通过冷启动攻击或物理访问挂起的设备来获取加密密钥，从而威胁用户数据安全。目前社区正在紧急修复这一回归问题，建议依赖磁盘加密的用户关注内核更新。
