Linux 内核社区热点与趋势

Linux 7.0-rc1 正式发布，合并窗口顺利关闭
Linux 内核 7.0 版本的第一个候选版本已正式发布，标志着本次合并窗口的结束。本次合并共包含 11,588 个非合并提交，涵盖了大量驱动更新和核心子系统改进，其中 WiFi 驱动 rtl8723bs 意外获得了大量代码清理关注。这一版本的发布为接下来的测试和稳定周期奠定了基础。
原文：7.0-rc1: mainline

多款 LTS 内核版本维护周期获得延长
稳定版维护者 Greg Kroah-Hartman 宣布延长 Linux 6.18、6.12 和 6.6 三个长期支持（LTS）系列的维护期限。其中 6.6 版本将支持至 2027 年底，而 6.12 和 6.18 将支持至 2028 年底，为企业级用户提供了更长久的系统稳定性保障。
原文：Linux 6.18 LTS / 6.12 LTS / 6.6 LTS Support Periods Extended

开发者正在为 Linux 7.1 开发一项令人期待的新特性，即基于 sched_ext 的 cgroup 子调度器支持。该功能允许在 cgroup 层面进行更精细的 CPU 资源调度管理，进一步增强了内核在复杂工作负载下的灵活性。
原文：Sub-Scheduler Support Could Be One Of The Most Exciting Features To Come For Linux 7.1

内核合并 RK3588 与 RK3576 视频解码器支持
瑞芯微（Rockchip）的高性能芯片 RK3588 和 RK3576 的视频解码器驱动已正式合并至 Linux 主线内核。这意味着使用这些芯片的单板计算机和嵌入式设备将能够获得原生的硬件加速解码能力，显著提升多媒体处理性能。
原文：RK3588 and RK3576 video decoders support merged in the upstream Linux Kernel

clone3() 系统调用拟引入 AUTOREAP 等新标志
内核开发者 Christian Brauner 提议为 clone3() 增加两个新标志，其中 AUTOREAP 标志允许进程在退出时自动回收，无需父进程等待。这一提议旨在优化 pidfd 机制下的进程管理，但在安全模型方面引发了社区的一定争议。
原文：As ye clone(), so shall ye AUTOREAP

BPF 硬件内存隔离方案讨论遇冷
