Linux 7.3 显著提升显存超额使用时的性能
在最新的 Linux 7.3 内核更新中，针对显存（vRAM）耗尽后的性能表现进行了深度优化。当 GPU 任务超出物理显存容量时，新机制能更高效地处理内存置换，减少系统卡顿。这一改进对于在有限硬件资源上运行大型 AI 模型或高性能图形应用的开发者来说具有重要意义。

Fedora 计划限制并逐步淘汰 AF_ALG 接口
由于 Linux 内核的 AF_ALG（加密算法用户态接口）近期频发高危安全漏洞（如 Copy Fail 等），Fedora 社区决定在下一版本中限制其使用。内核开发者 Eric Biggers 等人正推动将该接口彻底从内核中移除。此举旨在迫使开发者转向更安全的加密实现方式，提升整体系统安全性。
原文：Fedora prepares for the end of AF_ALG

BSDun：为 Linux 内核引入 FreeBSD ELF 支持
BSDun 项目尝试在 Linux 内核中实现对 FreeBSD 可执行文件（ELF 格式）的原生支持。该项目通过在 Linux 层面模拟 FreeBSD 的系统调用接口，旨在让用户无需虚拟机即可直接运行 FreeBSD 平台的二进制程序。这为跨平台系统研究和旧有应用迁移提供了新的可能性。
原文：BSDun – FreeBSD ELF support for the Linux kernel

CachyOS 在高端工作站上的性能表现优于主流发行版
最新的性能评测显示，基于 Arch Linux 的衍生版 CachyOS 在价值 4.6 万美元的高端工作站上展现了卓越的性能。通过针对特定 CPU 架构的编译优化和内核调度器调整，它在多项基准测试中超越了 Ubuntu 和 Fedora。这再次引发了社区关于发行版特定优化对现代硬件性能释放影响的讨论。

学术界最新研究

Agent libOS：为自进化 LLM 智能体打造的库操作系统
研究人员提出了一种名为 Agent libOS 的新型操作系统基座，专门用于管理具有自进化能力的 LLM 智能体。该系统通过分离操作准入和信息流准入，解决了智能体在获取新技能、分叉子进程时可能出现的权限提升风险。这是操作系统理论在 AI 智能体安全管控领域的一次重要探索。

CryptDough：面向安全多方计算的统一分析引擎
CryptDough 是一项关于安全多方计算（MPC）的最新研究，旨在为互不信任的多方提供统一的数据分析运行时。它支持关系运算、时间序列分析和机器学习推理，并引入了“虚拟向量”概念简化编程。该研究为保护隐私的大数据协作提供了高性能的系统级支撑。
原文：CryptDough: A Unified Analytics Engine for Secure Multiparty Computation

KernelArc：利用多智能体框架自动优化 GPU 内核
KernelArc 提出了一种自动化框架，利用多个专业化智能体协同优化 GPU 内核代码。该系统在 NVIDIA H100 和 B200 上进行了验证，成功优化了包括 BF16 GEMM 和混合专家模型（MoE）在内的多种复杂算子。实验结果显示，其生成的内核性能在多个基准测试中达到了业界领先水平。
原文：KernelArc: A Multi-Agent Framework for GPU Kernel Optimization

Aegis：智能体 AI 的运行时治理与故障闭锁执行
针对 AI 智能体可能产生的有害操作副作用，Aegis 系统提出了一种运行时治理模型。它将模型输出视为“行动提案”，并在执行前通过受信任的决策层进行中介校验。该系统支持“故障闭锁”（Fail-Closed）机制，确保在不确定情况下拒绝执行潜在危险指令，为 AI 自动化提供了安全防线。
原文：Runtime Governance for Agentic AI: Action-Boundary Control with Trusted Provenance and Fail-Closed Execution

SkillEffect：针对内存受限智能体工具的检查降级机制

原文：SkillEffect: Checked Lowering for Memory-Bounded Agent Tools
