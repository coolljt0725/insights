学术界最新研究

从 C 到地道 Rust：基于 Agent 的代码迁移研究
由于 C 语言存在内存安全隐患，将其迁移到 Rust 是系统编程的趋势，但手动迁移极其困难。该研究提出了一种“忒修斯之船”式的 Agent 翻译方法，利用 AI 代理逐步将 C 代码重构为符合 Rust 惯用法的安全代码。这种方法不仅保证了功能等价，还通过静态所有权模型消除了潜在的内存漏洞。

LearnedCache：基于 eBPF 和感知机的 Linux 页面缓存替换策略
研究人员开发了 LearnedCache，这是一种集成在 Linux 内核中的机器学习页面缓存驱逐策略。它利用 eBPF 框架在内核态运行轻量级感知机模型，根据实时负载特征预测页面重用情况。实验表明，这种自适应策略在减少磁盘访问和提升系统整体性能方面优于传统的启发式算法。
原文：LearnedCache: eBPF-Integrated Perceptron-Based Eviction Policies for the Linux Page Cache

拓扑感知的数据移动：优化分布式 GPU 推理中的 KV 缓存传输
在分离式 LLM 推理中，KV 缓存的传输带宽在不同物理连接下差异巨大（NVLink 与 TCP 差异达 72 倍）。该研究设计了一个拓扑感知调度器，能在启动时自动发现互联层级并选择最优传输路径。这种方法显著降低了分布式推理的延迟，解决了大规模生产环境下的网络瓶颈问题。
原文：Topology-Aware Data Movement for Disaggregated GPU Inference

当神经网络准确预测物理系统时，它是否真的学到了结构化的物理知识？LAWFUL 框架通过因果一致性度量和不变性验证，量化了网络内部计算与物理定律之间的关联。该研究为物理信息机器学习（PIML）的可解释性和可靠性提供了重要的理论支撑。
原文：LAWFUL: Law-Aligned Witness for Faithful Use of Latents
