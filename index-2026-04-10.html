学术界最新研究

Quine：将 LLM Agent 实现为原生 POSIX 进程
研究人员提出了 Quine 架构，主张直接利用成熟的操作系统机制（如 PID、标准流、环境变量）来管理 LLM Agent，而非在应用层构建复杂的编排器。通过将 Agent 映射为 POSIX 进程，Quine 能够继承操作系统的隔离性、调度能力和通信机制。这种回归系统底层的思路为 AI 代理的标准化提供了新路径。
原文：Quine: Realizing LLM Agents as Native POSIX Processes

Blink：基于 SmartNIC 和 GPU 的免 CPU 推理架构
Blink 提出了一种端到端的推理架构，旨在将主机 CPU 从 LLM 推理的关键路径中移除。该系统通过 SmartNIC 直接处理请求并利用 RDMA 将数据送入 GPU 显存，由 GPU 常驻内核负责调度。这种设计消除了 CPU 干扰对推理性能的影响，显著提升了数据中心的资源利用率。
原文：Blink: CPU-Free LLM Inference by Delegating the Serving Stack to GPU and SmartNIC

Valve：在线与离线推理混部的延迟边界保障系统
针对 LLM 推理流量的突发性导致的资源浪费，Valve 系统提出了一种在线与离线任务混部方案。该系统能够在保障在线请求亚毫秒级抢占延迟的前提下，充分利用空闲算力进行离线推理。其核心贡献在于通过联合限制抢占延迟和抢占率，解决了生产环境中混部任务相互干扰的难题。
原文：Valve: Production Online-Offline Inference Colocation with Jointly-Bounded Preemption Latency and Rate

VCAO：基于验证者中心代理编排的 OS 漏洞发现框架
该研究将操作系统漏洞发现建模为一个博弈过程，利用大推理模型（LRM）作为编排器，动态分配分析预算。系统结合了静态分析、模糊测试和消毒器等多种外部验证工具，通过贝叶斯信念更新来优化攻击路径的选择。实验表明，这种自动化的编排方式能更有效地发现内核中的深层漏洞。
原文：VCAO: Verifier-Centered Agentic Orchestration for Strategic OS Vulnerability Discovery
