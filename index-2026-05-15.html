Linux 内核社区热点与趋势

近期 Linux 内核连续曝出多个高危本地权限提升漏洞，安全形势严峻。 继 Dirty Frag 和 Fragnesia 之后，名为 ssh-keysign-pwn 的新漏洞（影响 5.10 及以上版本）被公开，该漏洞利用 ptrace_may_access 与 pidfd_getfd 的逻辑缺陷，允许非特权用户读取 root 拥有的文件。尽管 Greg Kroah-Hartman 发布了 7.0.7、6.18.30 和 6.12.88 等多个稳定版内核，但目前的更新尚未包含 Fragnesia 的补丁，社区正面临巨大的修复压力。
原文：New Linux LPE, 5.10 and above (ptrace_may_access mm-NULL + pidfd_getfd)

2026 年 Linux 存储、文件系统、内存管理与 BPF 峰会（LSFMM+BPF）深入讨论了内存管理架构的革新。 Chris Li 提出了“策略组（Policy Groups）”概念，旨在解决当前 Control Groups 在资源管理之外的局限性，特别是在复杂内存分配策略上的不足。同时，Lorenzo Stoakes 提出了“COW 上下文”方案，试图重构被视为“破碎抽象”的匿名页反向映射机制，以提升性能并降低代码复杂度。
原文：Policy groups for memory management

Intel 与 AMD 在内核调度与硬件支持方面取得新进展。 Intel 领导的“缓存感知调度（Cache Aware Scheduling）”补丁集在经过一年的测试后，因其在 Intel 和 AMD 处理器上显著的性能提升，正接近合并入主线内核。与此同时，AMD 正在为 Linux 7.2 内核准备 AIE4 NPU 硬件支持，并修复了 Linux 7.1 中动态 EPP（能源性能偏好）功能引发的初期问题。
原文：Intel's Cache Aware Scheduling Inches Closer To Being Merged For Linux

学术界最新研究

SemaTune：利用大语言模型实现语义感知的在线操作系统调优。 来自 arXiv 的研究提出了一种名为 SemaTune 的框架，它将操作系统的配置参数、遥测数据和历史记录转化为决策上下文，利用 LLM 的推理能力进行动态调优。该方法克服了传统黑盒优化无法理解参数间逻辑结构的缺陷，显著提升了长周期服务的运行效率。
原文：SemaTune: Semantic-Aware Online OS Tuning with Large Language Models

EMA：面向学习型系统的高效模型自适应框架。 针对网络负载和运行目标不断变化的动态环境，EMA 系统支持学习型系统以极低的开销实现模型自适应。相比于传统的重新训练，EMA 能够快速响应环境漂移，减少数据采集需求，确保系统在异构长周期运行中的性能稳定性。
原文：EMA: Efficient Model Adaptation for Learning-based Systems

HodgeCover：利用高阶拓扑覆盖驱动稀疏混合专家模型（MoE）的压缩。 研究发现，现有的 MoE 压缩算法往往忽略了专家之间的三元兼容性，导致合并时出现结构性障碍。该论文引入了单纯复形拉普拉斯算子的调和核概念，通过 Hodge 分解精确识别可合并的专家组，在不损失精度的情况下大幅降低了推理成本。
原文：HodgeCover: Higher-Order Topological Coverage Drives Compression of Sparse Mixture-of-Experts
