Linux 内核社区热点与趋势

Linux 7.2-rc2 发布：开发进度平稳符合预期
Linus Torvalds 发布了 Linux 7.2 的第二个候选版本（rc2），并表示目前的开发状态非常“正常”。虽然 rc2 的代码量不算小，但与最近几个版本相比基本持平，甚至略小于 7.1-rc2。这预示着 7.2 版本的开发正处于稳定轨道上，若无重大意外，正式版有望在 8 月发布。

AMD 与 Intel 开启 Linux 7.3 显卡驱动预研工作
尽管 7.2 版本尚在测试，AMD 和 Intel 已开始向 DRM-Next 提交针对 Linux 7.3 内核的驱动补丁。AMD 侧重于 AMDKFD 内核流驱动的更新，而 Intel 则在为下一代 Nova Lake 笔记本的 IPU8 图像处理单元提供支持。这些工作确保了 Linux 内核能够第一时间适配未来的高性能硬件架构。
原文：AMD Begins Staging Graphics Driver Changes For Linux 7.3

BSDun 模块：在 Linux 上直接运行 FreeBSD 二进制文件
开发者发布了一个名为 BSDun 的新 Linux 内核模块，旨在让 Linux 能够直接加载并执行 FreeBSD 的 ELF 二进制文件。该项目通过在内核层处理系统调用差异，尝试实现跨 BSD 与 Linux 的二进制兼容性。这为需要在 Linux 环境下运行特定 BSD 工具的用户提供了新的技术路径。
原文：BSDun – Linux kernel module to load FreeBSD ELF binaries

Linux 安全增强：开源“死人开关”与 USB 杀戮开关项目
GitHub 上出现了一个名为 luks-deadman 的安全项目，为 Linux 系统提供了“死人开关”和 USB 自动销毁机制。该工具可以在特定触发条件（如拔掉特定 USB 设备或长时间无操作）下自动锁定 LUKS 加密分区或执行安全擦除。这对于处理敏感数据的安全从业者和隐私保护者具有重要的实战意义。
