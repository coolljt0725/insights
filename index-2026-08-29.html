Linux 内核社区热点与趋势

Linux 内核 CVE 数量激增，单次发布接近 2000 个
随着 AI 和大语言模型（LLM）被广泛用于分析 Linux 内核庞大的代码库，内核漏洞（CVE）的报告数量出现了爆炸式增长。以往每个内核版本的 CVE 修复数量通常在 500 个左右，而现在这一数字正逼近 2000 个，预计在 Linux 7.3 版本中可能会突破这一门槛。这种趋势虽然有助于提升安全性，但也给内核维护者带来了巨大的审核压力。
原文：The Linux Kernel Is Approaching 2,000 CVEs Per Release

Linux 7.3 引入 USB-C 线缆特性检查与旧驱动清理
即将发布的 Linux 7.3 内核在 USB 子系统中引入了重要更新，将开始检查 USB-C 线缆是否支持“替代模式”（Alt-mode），并增加了低延迟的 USB4STREAM 选项以优化数据传输。与此同时，社区继续清理过时硬件驱动，移除了一些长期无人维护且可能存在安全隐患的 IBM 和 SGI 旧驱动。这一举措旨在减轻因 AI 生成的大量错误报告而增加的维护负担。
