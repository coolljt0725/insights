PolyQ：面向边缘 CPU 的 LLM 推理端到端量化框架
来自 arXiv 的研究提出了一种名为 PolyQ 的编译器与量化协同设计框架，旨在解决边缘 CPU 上低比特量化执行效率低下的问题。PolyQ 通过激活感知的通道级比特分配，并利用编译时模型编译器将通道聚类为位齐次块，生成兼容 SIMD 的内核。实验表明，该方法能在保持模型精度的同时，显著提升 CPU 上的推理速度。
原文：PolyQ: Codesigning End-to-End Quantization Framework for Scalable Edge CPU LLM Inference

TEDDY：基于 ICD 诊断历史的儿科疾病预警基础模型
研究人员开发了名为 TEDDY 的解码器 Transformer 模型，该模型基于 160 万儿童的 7300 万条 ICD-10 诊断记录进行训练。TEDDY 能够建模纵向诊断轨迹和就诊时间，在 797 项疾病发作预测任务中表现优异，中位数 AUC 达到 72.0%。这一成果展示了生成式基础模型在儿科临床轨迹预测和早期风险预警中的巨大潜力。
原文：TEDDY: A Pediatric Foundation Model for Risk Forewarning from ICD-Coded Diagnostic Histories

ExaGEMM：通过寄存器内关联计算驱动 CPU 上的低比特机器学习推理
针对传统 CPU 不擅长处理极低比特（1/2/4比特）GEMM 运算的问题，ExaGEMM 框架提出了一种基于寄存器内查找表（LUT）执行的新思路。该框架利用现有的 SIMD 数据通路进行表生成和累加，仅需极小的硬件改动即可实现高效的低比特运算。这种软硬件协同设计为在通用 CPU 上部署高性能 AI 模型提供了新路径。
原文：ExaGEMM: Exploration Framework for CPU-Driven ML Inference via Associative In-Register Computing for Low-Bit GEMM
