FairyFuse：在普通 CPU 上实现无乘法的 LLM 高效推理
来自 arXiv 的研究提出了一种名为 FairyFuse 的推理系统，通过融合三元权重内核，在商品化 CPU 上实现了无乘法执行。该研究利用三元权重（-1, 0, +1）将复杂的浮点乘法替换为条件加减法，显著降低了内存带宽压力。实验表明，这种方法在不损失模型质量的前提下，大幅提升了 CPU 平台上的自回归生成速度。
原文：FairyFuse: Multiplication-Free LLM Inference on CPUs via Fused Ternary Kernels

Absorber LLM：利用因果同步实现长文本测试时训练
针对 Transformer 在处理长序列时计算成本激增的问题，研究者提出了 Absorber LLM。该模型将长上下文保留公式化为自监督的因果同步过程，通过在测试时将历史上下文“吸收”到模型参数中，实现了常数级内存占用。这种方法有效克服了传统 RNN 或 SSM 在处理长尾依赖时的局限性。

揭示 LLM 的“工具过度使用幻觉”及其缓解策略
一项最新的研究揭示了 LLM 在推理过程中普遍存在的“工具过度使用”现象，即模型在拥有内部知识的情况下仍盲目调用外部工具。研究者将其归因于“知识认识论幻觉”，即模型无法准确判断自身的知识边界。为此，他们提出了一种基于直接偏好优化的知识感知边界对齐策略，显著提升了模型在决策时的效率和准确性。
