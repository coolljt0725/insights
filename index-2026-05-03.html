Linux 内核修复 CVE-2026-31431 “Copy Fail” 高危漏洞
近期披露的 CVE-2026-31431（被称为“Copy Fail”）是一个影响 Linux 内核 algif_aead 模块的本地特权提升漏洞。该漏洞自 2017 年起便存在于内核中，直到最近才被 AI 在约一小时内发现，暴露了内核安全审计的长期盲点。目前各大发行版如 Ubuntu 已紧急发布补丁，社区也在讨论如何通过禁用 AF_ALG 接口来减少攻击面。

Linux 7.1 将修复 Steam Deck OLED 版长达两年的音频故障
由于 2023 年底合并到 Linux 6.8 的一项 AMD ASoC 音频变更，Steam Deck OLED 版在主线内核中一直无法正常驱动音频。虽然 Valve 的官方系统通过补丁规避了此问题，但主线内核直到 Linux 7.1-rc2 才真正解决了这一历史遗留问题。这一修复将极大改善在 Steam Deck 上运行非官方 Linux 发行版的用户体验。
