Linux 内核社区热点与趋势

Linux 6.19 正式版发布，标志着 6.x 时代的终结
Linus Torvalds 正式发布了 Linux 6.19 内核，这一版本引入了多项重要更新，包括对 Intel 线性地址空间分离（LASS）的初步支持、Arm 内存系统资源分区与监控（MPAM）以及新的 listns() 系统调用。该版本是 6.x 系列的最后一个主版本，随后内核开发将正式进入 7.0 时代。此次更新还改进了 ext4 文件系统对大块大小的支持，并增强了网络栈的内存安全性。

Linux 7.0 合并窗口开启，Rust 实验阶段正式宣告结束
随着 Linux 7.0 合并窗口的开启，内核社区正式宣布结束 Rust 语言的“实验性”阶段，将其视为内核开发的常规组成部分。7.0 版本将引入大量新特性，包括调度器的性能优化与可扩展性增强，旨在更好地支持高核心数系统。此外，SpacemiT K3 RVA23 等 RISC-V SoC 的主线支持也将被纳入，显示出内核对新兴架构的持续投入。

在 Linux 7.0 的更新中，高性能异步 I/O 框架 IO_uring 获得了 BPF 过滤支持。这一特性允许开发者在内核态通过 BPF 程序对 I/O 请求进行精细化过滤和处理，减少了用户态与内核态之间的上下文切换开销。这对于需要处理海量小 I/O 请求的高并发应用（如数据库和高性能 Web 服务器）具有显著的性能提升意义。

AgentCgroup：理解并控制 AI 智能体的操作系统资源
来自 arXiv 的研究论文介绍了 AgentCgroup 框架，旨在解决 AI 智能体在云环境中执行工具调用时资源需求剧烈波动的问题。研究发现，OS 级别的执行（如容器初始化和工具调用）占到了端到端延迟的 56-74%，且内存而非 CPU 是主要的并发瓶颈。AgentCgroup 通过系统化的资源表征，为多租户环境下智能体的高效调度提供了理论依据。

针对 LLM 推理中全局 KV-Cache 共享带来的隐私泄露风险，论文提出了 SafeKV 系统。该系统通过在服务运行时集成轻量级检测与隔离机制，消除了跨租户重用敏感缓存块的可能性，同时保留了全局共享带来的大部分性能收益。这一研究为构建安全、高效的多租户 AI 推理平台提供了关键的技术方案。
